# npm package — `@4sh/ui-kit`

This Design System's components are published as **a single npm
package**, consumable by any Angular application.

```bash
npm install @4sh/ui-kit
```

<div className="sb-callout">

**No risk of forgetting to install something.** `@4sh/ui-kit` is a **single
package** with *secondary entry points* — not a collection of separate
packages. Every entry point is present as soon as you run `npm install`, and
dependencies between them resolve automatically: importing `UiDatepicker`
pulls in everything it needs (its form base, its icons…) without you having
to declare anything.

</div>

```ts
import { UiDatepicker } from '@4sh/ui-kit/forms/ui-datepicker';

@Component({
  selector: 'app-booking',
  imports: [UiDatepicker],
  template: `<ui-datepicker label="Date" valueType="date" [(ngModel)]="date" />`,
})
export class Booking { date = signal<Date | null>(null); }
```

The entry point's name is the component's name: each component's doc page,
in the sidebar, gives the exact import to copy.
