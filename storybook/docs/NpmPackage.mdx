# Package npm — `@4sh/ui-kit`

Les composants de ce Design System sont publiés sous forme d'**un seul package
npm**, consommable par n'importe quelle application Angular.

```bash
npm install @4sh/ui-kit
```

<div className="sb-callout">

**Pas de risque d'oubli d'installation.** `@4sh/ui-kit` est un **package unique**
avec des *secondary entry points* — pas une collection de packages séparés. Tous
les entry points sont présents dès `npm install`, et les dépendances entre eux
se résolvent automatiquement : importer `UiDatepicker` tire tout ce dont il a
besoin (son socle de formulaire, ses icônes…) sans que vous ayez quoi que ce
soit à déclarer.

</div>

```ts
import { UiDatepicker } from '@4sh/ui-kit/ui-datepicker';

@Component({
  selector: 'app-booking',
  imports: [UiDatepicker],
  template: `<ui-datepicker label="Date" valueType="date" [(ngModel)]="date" />`,
})
export class Booking { date = signal<Date | null>(null); }
```

Le nom de l'entry point est celui du composant : la page de doc de chaque
composant, dans la barre latérale, donne l'import exact à recopier.

## Le mode d'emploi complet vit dans le README du package

Installation, liste des entry points, feuille de styles à charger, providers
attendus par `ui-image` et `BrandService`, construction de votre propre champ
sur `@4sh/ui-kit/forms` : tout est décrit **une seule fois**, dans le README
livré avec le package — c'est aussi ce qu'affiche la page npmjs.
