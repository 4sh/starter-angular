## Floating panels (`$overlay-panel-*`)

Shared structure of **floating panels** (`ui-menu`'s dropdown, `ui-datepicker`'s calendar,
future select/multiselect…), consumed via the `utils.overlay-panel($surface, $stroke)`
mixin. **Colors** aren't here: each component passes its own token family to the
mixin (menu → `navigation.*`, forms → `form.*`) — restyling one family doesn't affect
the others. Per-instance escape hatch via the `--ui-overlay-radius` / `--ui-overlay-shadow` /
`--ui-overlay-surface` / `--ui-overlay-stroke` custom properties.

## Motion (`$motion-*`)

Shared timing for the **motion system** (enter/exit presets + state transitions).
Consumed by `utils.motion-transition()`, `base/_motion.scss` and the `[uiMotion]` directive.
Overridable per element via the `--ui-motion-*` custom properties. See **Foundations → Motion**.
