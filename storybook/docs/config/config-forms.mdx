# Configuration: Forms category

Constants of the **forms** family (`$form-*`). Each variable inherits a global value by
default and can be overridden for **all** form controls at once.

> Source file: `projects/ui-kit/styles/settings/_ui-config.scss` · exposed via `@use 'utils'`.
> Consumed by: `ui-checkbox`, `ui-radio`, `ui-toggle`, `ui-field` (hence `ui-input`,
> `ui-input-mask`, `ui-input-number`, `ui-textarea`). Back to
> [how it works & summary](?path=/docs/components-configuration--docs).
