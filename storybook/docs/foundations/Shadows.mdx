# Shadows & effects

Shadows are exposed as ready-to-use **composite styles**, generated from
`src/design-tokens/styles.json`: a CSS variable `--shadow-{category}-{size}` (full
`box-shadow` value) **and** a utility class `.shadow-{category}-{size}`.

- **Categories**: `default`, `highlight`, `success`, `warning`, `error` (color = `--effects-*` token, theme-aware).
- **Sizes**: `sm`, `md`, `lg`.

```scss
/* SCSS (component) */
.my-card { box-shadow: var(--shadow-default-md); }
```

```html
<!-- HTML / template : classe utilitaire -->
<div class="shadow-success-lg">…</div>
```

export const CATS = ['default', 'highlight', 'success', 'warning', 'error'];
export const SIZES = ['sm', 'md', 'lg'];

export const Box = ({ cat, size }) => (
  <div
    className={`shadow-${cat}-${size}`}
    style={{
      width: 150, height: 78, borderRadius: 12, display: 'flex', alignItems: 'center', justifyContent: 'center',
      background: 'var(--global-background-default)', color: 'var(--global-text-default)', fontSize: 13,
    }}>
    shadow-{cat}-{size}
  </div>
);

{CATS.map((cat) => (
  <div key={cat} style={{ display: 'flex', gap: 32, padding: '20px 4px', flexWrap: 'wrap', alignItems: 'center' }}>
    {SIZES.map((size) => <Box key={size} cat={cat} size={size} />)}
  </div>
))}

## Effect colors

Each shadow draws its color from a semantic `--effects-*` token (light/dark handled at runtime).

export const Eff = ({ name }) => (
  <tr>
    <td><span style={{ display: 'inline-block', width: 28, height: 28, borderRadius: 6, background: `var(--effects-${name})`, verticalAlign: 'middle' }} /></td>
    <td><code>--effects-{name}</code></td>
  </tr>

## Raw tokens (low level)

The geometry comes from `metrics`: `--shadow-{sm|md|lg}-{positionx|positiony|blur|spread}`.
Generally, prefer the composite styles above; these raw tokens are for composing a
custom shadow.
