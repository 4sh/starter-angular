# Responsive Design

The project uses **[Gridaflex](https://www.npmjs.com/package/gridaflex)** (v1.0.0) as its responsive layout system. Gridaflex is a **flexbox** system with X / Y axes on a modern `gap` engine (never negative margins), building on Foundation's XY API, modernized.

> Class prefix: `flex-` — this is **not** CSS Grid.

## 1. Breakpoints

The tiers are defined in the design tokens (`src/design-tokens/responsive.json` → generated into `projects/ui-kit/styles/generated/_tokens-breakpoint.scss`) then injected into Gridaflex via `src/styles/src/vendors/gridaflex-settings.scss`.

## 2. Gridaflex mental model

1. An optional **container** `.flex-container` centers and bounds the width.
2. A **group** defines the axis: `.flex-x` (horizontal) or `.flex-y` (vertical).
3. **Cells** `.cell` sit inside the group and receive a responsive size `[breakpoint]-[n]` (n from 1 to **24** in this project, see `$flex-columns: 24`).
4. **Gutters** are set **on the group**: `.flex-gap-x` (horizontal), `.flex-gap-y` (vertical), `.flex-gap-xy` (both).

> Golden rule: **size** (`desktop-8`) goes on the **cell**; **gutter** (`flex-gap-x`) goes on the **group**. Don't swap them.

### Canonical skeleton

```html
<div class="flex-container">
  <div class="flex-x flex-gap-x">
    <div class="cell phone-24 tablet-portrait-12 desktop-8">A</div>
    <div class="cell phone-24 tablet-portrait-12 desktop-16">B</div>
  </div>
</div>
```

- Mobile-first: `phone-*` applies everywhere, then overridden upward.
- Fractions are **gap-aware**: 3× `desktop-8` (3 × 8 = 24 columns) fit exactly, gutter included.

## 3. Usage in SASS/SCSS

To apply conditional styles, use the `breakpoint()` mixin exposed by Gridaflex's Sass API.

### Standard syntax (Up)

Applies the styles from the specified tier and above.

```scss
@use 'gridaflex' as flex;

.my-element {
  width: 100%; // Mobile by default

  @include flex.breakpoint(tablet-portrait) {
    width: 50%; // Tablets and up
  }
}
```

### Useful variants

```scss
@use 'gridaflex' as flex;

// Exact range (only between tablet-portrait and tablet-landscape)
@include flex.breakpoint(tablet-portrait only) { … }

// Downward (desktop and below)
@include flex.breakpoint(desktop down) { … }

// Raw value (converted to em)
@include flex.breakpoint(768px) { … }

// Orientation / HiDPI
@include flex.breakpoint(landscape) { … }
@include flex.breakpoint(retina) { … }
```

### Semantic API (mixins, no utility classes)

```scss
@use 'gridaflex' as flex;

.gallery {
  @include flex.xy-flex;                       // display:flex + wrap
  @include flex.xy-flex-margin(xy);            // gutter on both axes
  @include flex.xy-flex-layout(3, '.item');    // 3 items per row
}

.sidebar {
  @include flex.xy-cell(1 of 4);               // 25%, gap-aware
  @include flex.breakpoint(desktop) {
    @include flex.xy-cell(8);                  // 8 / 24 columns on desktop
  }
}
```

## 5. One-off override via CSS variables

To adjust a gutter on a single instance, without touching the config:

```html
<div class="flex-x flex-gap-x"  style="--flex-gap-x: 8px">…</div>
<div class="flex-x flex-gap-xy" style="--flex-gap-x: 8px; --flex-gap-y: 16px">…</div>
```

## 6. Project configuration

Gridaflex's configuration is centralized in `src/styles/src/vendors/gridaflex-settings.scss` and fed by the responsive design tokens:

- **`$flex-columns: 24`**: the grid is on 24 columns (rather than the default 12).
- **`$breakpoints`**: synced with the tokens (`phone`, `tablet-portrait`, `tablet-landscape`, `desktop`, `medium-desktop`, `big-desktop`).
- **`$flex-margin-gutters`**: gutters per breakpoint (16px on phone, 24px from tablet-portrait up).
- **`$gutters` / `$padding-gutters`**: `default: 16px` key (used by `flex-gap-x/y/xy`).

> Any change to these settings must go through the design tokens, never hardcoded in a component.

## 7. Mistakes to avoid

- ❌ Putting the **size** (`desktop-8`) on the group, or the **gutter** (`flex-gap-x`) on the cell.
- ❌ Using negative margins or `overflow-x: hidden` to "fix" overflow: unnecessary, the `gap` engine never creates any.
- ❌ Confusing this with **CSS Grid** (`grid-template-*`): this is **flexbox**.
- ❌ Inventing a breakpoint or a size outside the config (n ranges from 1 to 24 in this project).
- ❌ Using the deprecated `grid-*` / `flex-margin-*` / `xy-grid-*` aliases (Foundation compat) in new code: prefer `flex-*` / `flex-gap-*` / `xy-flex-*`.
- ❌ Placing `@use 'gridaflex/src/settings' with (…)` after `@use 'gridaflex/src/classes'`: the config would be ignored.
