# Theme & Token System

This starter uses **no proprietary UI library**. The theme rests entirely on
**design tokens** generated as CSS variables, consumed by the components.

## Pipeline

```
src/design-tokens/*.json        (DTCG source, Token Flow Manager export)
        │  npm run tokens:build  (scripts/tokens.build.mjs)
        ▼
projects/ui-kit/styles/generated/_tokens-*.scss   (CSS variables)
        ▼
components (co-located .scss) + utility classes (typo…)
```

## Runtime services

Two Angular services (`providedIn: 'root'`, signals + `effect`) drive these attributes on
`<html>`. They are **headless and UI-dependency-free**: they only set an attribute,
all the rendering follows from the CSS tokens. They are instantiated in `AppComponent` (their
`effect` applies the attribute on startup and on every signal change).

### ThemeService: light / dark

`src/app/core/service/theme.service.ts`

- **State**: `currentMode` (signal `'light' | 'dark'`), initialized from `localStorage` (key `theme-mode`), default `'light'`.
- **Effect**: `dark` → `document.documentElement` receives `[data-theme='dark']`; `light` → the attribute is removed (the `:root` semantics apply). The choice is persisted in `localStorage`.
- **API**: `toggle()` (switches light/dark), `isDark` (boolean getter), `currentMode.set(...)`.

```ts
private theme = inject(ThemeService);

this.theme.toggle();          // light ⇄ dark, persisted
this.theme.currentMode.set('dark');
const dark = this.theme.isDark;
```

### BrandService: brand (color theme)

`src/app/core/service/brand.service.ts`

- **State**: `currentBrand` (signal `'brand1' | 'brand2' | 'brand3'`), initialized from the **subdomain** (`themeone → brand1`, `themetwo → brand2`, `themethree → brand3`), default `'brand1'`.
- **Effect**: `brand1` (default) → no attribute (`:root` primitives = brand 1); `brand2`/`brand3` → `[data-brand='brand2'|'brand3']`, which redefines the `--primitives-*` and propagates to the semantics that reference them.
- **API**: `set(brand)`, `currentBrand()` (read).

```ts
private brand = inject(BrandService);

this.brand.set('brand2');           // activates brand 2's palette
const current = this.brand.currentBrand();
```

> Unlike the theme, the brand is **not persisted**: it derives from the subdomain
> (multi-tenant). The **Foundations → Colors** explorer lets you force brand + mode to
> preview the tokens, without altering the rest of the Storybook UI.
