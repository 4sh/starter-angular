# ui-image

Composant d'image générique piloté par une source (`src`) fournie directement par le consommateur. Il supporte les formats bitmap (JPG, PNG…) via `NgOptimizedImage` (lazy-loading, priorité LCP) et les SVG, injectés inline pour permettre leur stylisation via CSS. Deux options activables : `authenticated` pour récupérer une image protégée (requête HTTP en blob), et `preview` pour ouvrir une lightbox plein écran (`ui-lightbox`) avec zoom et rotation.

## Règles d'utilisation (DOs & DON'Ts)

<table>
  <thead>
    <tr>
      <th>DO</th>
      <th>DON'T</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>
        Toujours fournir l'attribut <code>src</code> avec le chemin ou l'URL complète de l'image :
        <pre><code>{`<ui-image
  src="assets/img/common/svg/logo.svg"
  [width]="200"
  widthUnit="px"
  alt="Logo de l'application">
</ui-image>`}</code></pre>
      </td>
      <td>
        Ne pas activer <code>[authenticated]="true"</code> pour une image publique classique — cela déclenche une requête HTTP en blob inutile et empêche le lazy-loading de <code>NgOptimizedImage</code> :
        <pre><code>{`<!-- INCORRECT -->
<ui-image src="assets/img/common/jpg/photo.jpg" [authenticated]="true">
</ui-image>`}</code></pre>
      </td>
    </tr>
    <tr>
      <td>
        Utiliser <code>[fill]="true"</code> avec un conteneur parent en <code>position: relative</code> pour les images en mode remplissage :
        <pre><code>{`<!-- Conteneur parent -->
<div style="width: 400px; height: 300px; position: relative;">
  <ui-image src="assets/img/common/jpg/hero.jpg" [fill]="true" alt="Hero"></ui-image>
</div>`}</code></pre>
      </td>
      <td>
        Ne pas utiliser <code>[fill]="true"</code> en même temps que <code>[width]</code> ou <code>[height]</code> — ces propriétés sont mutuellement exclusives avec <code>fill</code> :
        <pre><code>{`<!-- INCORRECT -->
<ui-image
  src="assets/img/common/jpg/hero.jpg"
  [fill]="true"
  [width]="400">
</ui-image>`}</code></pre>
      </td>
    </tr>
  </tbody>
</table>
