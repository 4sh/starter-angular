# ui-rating

Le composant `ui-rating` permet à l'utilisateur de donner une note sur une échelle (par défaut 5 étoiles). Il est construit sur un `<input type="range">` invisible, garantissant l'accessibilité native (clavier, lecteur d'écran, formulaire).

<Canvas of={UiRatingStories.Default} />

## API

<ArgTypes />

### Demi-étoiles

`allowHalf` fait passer le pas de sélection à **0,5** : le clic sur la moitié avant d'une
étoile pose la demi-note, le clic sur la moitié arrière l'étoile entière, et les flèches du
clavier avancent de 0,5 en 0,5 (le `step` de l'`<input type="range">` sous-jacent suit).
`cancel` reste actif sur la valeur exacte : re-cliquer la même moitié remet à `null`.

<Canvas of={UiRatingStories.AllowHalf} />

Le remplissage partiel ne dépend d'aucune icône dédiée : l'icône « on » est **superposée**
à l'icône « off » puis rognée (`clip-path`) à la fraction voulue. La demi-étoile fonctionne
donc telle quelle avec n'importe quelle famille d'icônes et avec les templates projetés
`#onIcon` / `#offIcon`, en LTR comme en RTL.

<Canvas of={UiRatingStories.HalfReadonly} />

### Tailles
La taille des étoiles et leur espacement sont gérés nativement via l'input `size` (`sm` à `xl`).

## Formulaires

Le composant est un `ControlValueAccessor` : il se branche sans code additionnel aux
**Signal Forms** (`@angular/forms/signals`, directive `[formField]`, stables depuis
Angular 22) via l'interop CVA native, ainsi qu'aux formulaires template-driven
(`[(ngModel)]`) et réactifs (`[formControl]`).

> ℹ️ **Valeur « non notée » = `null`** (type `number | null`) : le `cancel`
> (re-clic sur la note courante) et la remise à zéro au clavier émettent `null`,
> et `writeValue(null)` est préservé — `Validators.required` (ou `required()` en
> Signal Forms) rejette donc naturellement l'absence de note, sans workaround
> `min(1)`. *(Breaking : les versions antérieures émettaient la sentinelle `0`.)*

<Canvas of={UiRatingStories.SignalForms} />

```html
<!-- Signal Forms -->
<ui-rating [formField]="rating" ariaLabel="Note" />

<!-- Template-driven -->
<ui-rating [(ngModel)]="note" ariaLabel="Note" />

<!-- Reactive -->
<ui-rating [formControl]="noteCtrl" ariaLabel="Note" />
```
