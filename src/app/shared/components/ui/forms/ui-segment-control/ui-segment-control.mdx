# ui-segment-control

Contrôle segmenté headless : un choix parmi une courte liste de segments inline
(ou plusieurs avec `multiple`). Chaque segment est un `<button>` natif ; le groupe
porte la sémantique WAI-ARIA (`radiogroup`/`radio` en mode simple avec navigation
aux flèches et sélection au déplacement, `group`/`aria-pressed` en mode `multiple`).
En mode simple, un **indicateur glissant** se déplace sous le segment sélectionné,
cadencé par le [système de motion](?path=/docs/foundations-motion--docs) (respecte
`prefers-reduced-motion` et l'opt-out `motion`).

Compatible autonome, `[(ngModel)]`, Reactive Forms, ou Signal Forms (`[formField]`) —
c'est un `ControlValueAccessor`.

## Options

Les options acceptent trois formes :

```ts
// 1. Primitives — la valeur EST le label
options = ['Liste', 'Grille', 'Tableau'];

// 2. Objets { value, label?, icon?, disabled?, ariaLabel? }
options = [
  { value: 'list', label: 'Liste', icon: 'list' },
  { value: 'grid', label: 'Grille', icon: 'table-cells' },
];

// 3. Objets métier + mapping de champs
options = [{ id: 1, name: 'Liste', off: false }];
// <ui-segment-control optionValue="id" optionLabel="name" optionDisabled="off" />
```

Pour comparer des valeurs **objet** lors de la sélection, fournir `dataKey`
(ex. `dataKey="id"`).

## Template personnalisé

Le contenu d'un segment est surchargeable via l'input `[itemTemplate]`, qui reçoit
`{ $implicit, option, selected, index }`.

```html
<ui-segment-control [(ngModel)]="plan" [options]="plans" [itemTemplate]="item" ariaLabel="Forfait" />
<ng-template #item let-plan let-selected="selected">
  <strong>{{ plan.label }}</strong>
  <small>{{ plan.hint }}</small>
</ng-template>
```

## Icônes

Une option peut porter une `icon` (avec ou sans `label`). En mode **icon-only**
(aucun `label`), un `ariaLabel` par segment est **obligatoire** (nom accessible).

## Formulaires

Le composant est un `ControlValueAccessor`, donc il se branche à toutes les APIs de
formulaire sans code additionnel.

<Canvas of={SegmentStories.SignalForms} />
<Canvas of={SegmentStories.TemplateDriven} />
<Canvas of={SegmentStories.ReactiveForms} />

```html
<!-- Signal Forms -->
<ui-segment-control [formField]="color" [options]="colors" ariaLabel="Couleur" />

<!-- Template-driven -->
<ui-segment-control [(ngModel)]="view" name="view" [options]="views" ariaLabel="Affichage" />

<!-- Reactive -->
<ui-segment-control [formControl]="viewCtrl" [options]="views" ariaLabel="Affichage" />
```

- Le style **erreur s'applique automatiquement** quand le contrôle attaché est invalide
  **et** touché/modifié ; `invalid` permet de le forcer.
- `disabled` désactive tout le groupe (par input ou via `control.disable()`) ;
  une option objet `disabled` grise un seul segment.
