# Motion

**Lightweight, design-token-driven** animation system, designed to be
**toggleable, customizable and reusable** across every component (accordion
opening, dropdown, modal, a helper or toast appearing…).

It relies on **native CSS animations** and the native Angular API
`animate.enter` / `animate.leave` (no `@angular/animations` runtime dependency).
Two complementary primitives:

- **Enter/leave presets** — global classes `ui-motion-<preset>-enter|leave`
  for inserting/removing an element (`@if`, `@for`, overlays, toasts…).
- **State transitions** — the SCSS mixin `utils.motion-transition(...)` for a
  mounted element that toggles (collapsed/expanded accordion, visible/hidden tooltip…).

## Usage

### 1. `[uiMotion]` directive (recommended)

On a conditionally rendered element, the directive picks the preset, exposes the
`enter()`/`leave()` classes and applies the timing overrides:

```html
@if (open()) {
  <div class="panel"
       [uiMotion]="'zoom'" #m="uiMotion"
       [animate.enter]="m.enter()" [animate.leave]="m.leave()">…</div>
}
```

### 2. Panel in a CDK overlay — `motionOnInsert`

For any content rendered inside a **CDK overlay** (a `ui-select` panel, a `ui-menu` popup,
`ui-popover`…), the enter goes through `motionOnInsert` instead of `animate.enter`: the
directive sets the preset's class itself.

```html
<div class="ui-x-panel" [uiMotion]="'slide-down'" motionOnInsert>…</div>
```

This is a **constraint, not a preference**. `animate.enter` registers the node in Angular's
animation queue, resolved via the injector when the node disappears. If the application
is destroyed while an overlay is open, that step fails and interrupts the
destruction: the overlay is never unmounted and its panel stays displayed, detached from its
anchor, in the top-left corner of the screen. A CSS class doesn't have this problem — the
animation is identical, since the presets are plain CSS animations.

The rest of the API doesn't change: presets, `--ui-motion-*` overrides, `motionDisabled`,
`data-motion="off"` and reduced-motion apply the same way.

### 3. Global classes (CSS-only)

The same classes can be used directly with `animate.enter`/`animate.leave`:

```html
@if (open()) {
  <div animate.enter="ui-motion-slide-down-enter"
       animate.leave="ui-motion-slide-down-leave">…</div>
}
```

### 4. State transition (mounted element)

```scss
@use 'utils';
.panel {
  opacity: 0;
  @include utils.motion-transition(opacity, transform);
  &._open { opacity: 1; }
  @include utils.motion-reduce { transition-duration: 0.01ms; }
}
```

## Customization

Each element can be re-timed via the **custom properties** `--ui-motion-*` (through the
directive: `motionDuration`, `motionEasing`, `motionDelay`, `motionDistance`,
`motionScale`, or directly in CSS), with the **`$motion-*` tokens** as defaults:

<table className="doc-table">
  <thead>
    <tr><th>Custom property</th><th>Default (token)</th><th>Role</th></tr>
  </thead>
  <tbody>
    <tr><td>`--ui-motion-duration`</td><td>`--transition-default` (180ms)</td><td>Duration.</td></tr>
    <tr><td>`--ui-motion-easing`</td><td>`--transition-easeinout`</td><td>Curve (symmetric transitions).</td></tr>
    <tr><td>`--ui-motion-easing-enter`</td><td>`--transition-easeout`</td><td>Enter curve (deceleration).</td></tr>
    <tr><td>`--ui-motion-easing-leave`</td><td>`--transition-easein`</td><td>Leave curve (acceleration).</td></tr>
    <tr><td>`--ui-motion-delay`</td><td>`0ms`</td><td>Delay before starting.</td></tr>
    <tr><td>`--ui-motion-distance`</td><td>`0.5rem`</td><td>Offset of the `slide-*` presets.</td></tr>
    <tr><td>`--ui-motion-scale`</td><td>`0.96`</td><td>Starting scale of the `zoom` preset.</td></tr>
  </tbody>
</table>

## Disabling & accessibility

- **Per element**: `[motionDisabled]="true"` (directive) or `[motion]="false"` (accordion).
- **Global**: `data-motion="off"` on `<html>` neutralizes all of the kit's animations **and**
  transitions (same reset as reduced-motion).
- **System preference**: `prefers-reduced-motion: reduce` reduces every preset to an
  instant flash — the state still changes, with no motion.
