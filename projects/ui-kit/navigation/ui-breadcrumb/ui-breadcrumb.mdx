Fil d'Ariane **headless** : indique la position courante dans une hiérarchie de navigation.

## Basic

La position courante dans la hiérarchie : le dernier élément représente la page courante
(<code>aria-current="page"</code>) , il n'a typiquement pas de destination.

```html
<ui-breadcrumb
  [items]="[
    { icon: 'house', ariaLabel: 'Accueil', url: '/' },
    { label: 'Électronique', url: '/electronique' },
    { label: 'Clavier sans fil' },
  ]"
/>
```

## Route

Le fil s'utilise avec le routeur Angular pour naviguer entre les pages : `routerLink`
(chaîne ou tableau de segments) bascule chaque élément sur la directive `RouterLink`
(navigation SPA, comportement natif de l'ancre préservé). `queryParams` et `fragment`
sont transmis à la directive.

<Canvas of={BreadcrumbStories.Route} />

```html
<ui-breadcrumb
  [items]="[
    { icon: 'house', ariaLabel: 'Accueil', routerLink: '/' },
    { label: 'Catalogue', routerLink: '/catalogue', queryParams: { tri: 'prix' } },
    { label: 'Clavier sans fil' },
  ]"
/>
```

## Liens

Chaque élément rend directement son ancre — pas de composant intermédiaire — donc les
attributs d'un lien restent accessibles item par item :

<table className="doc-table">
  <thead>
    <tr>
      <th>Cas</th>
      <th>Rendu</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>url</code> (+ <code>target</code>, <code>rel</code>)</td>
      <td><code>&lt;a href&gt;</code>. <code>rel</code> vaut <code>noopener noreferrer</code> par défaut dès que <code>target="_blank"</code>.</td>
    </tr>
    <tr>
      <td><code>routerLink</code> (+ <code>queryParams</code>, <code>fragment</code>, <code>target</code>)</td>
      <td><code>&lt;a&gt;</code> piloté par <code>RouterLink</code> — prioritaire sur <code>url</code>.</td>
    </tr>
    <tr>
      <td><code>command</code> sans destination</td>
      <td><code>&lt;button type="button"&gt;</code> : une action n'est pas un lien (clavier + rôle corrects).</td>
    </tr>
    <tr>
      <td>aucune destination, ou <code>disabled</code></td>
      <td><code>&lt;span&gt;</code> : jamais d'ancre sans <code>href</code> (ni focusable ni annoncée comme lien).</td>
    </tr>
  </tbody>
</table>

<Canvas of={BreadcrumbStories.Links} />

```html
<ui-breadcrumb
  [items]="[
    { icon: 'house', ariaLabel: 'Accueil', routerLink: '/' },
    { label: 'Documentation', url: 'https://exemple.fr/docs', target: '_blank' },
    { label: 'Retour', command: onBack },
    { label: 'Archivé', url: '/archive', disabled: true },
    { label: 'Page courante' },
  ]"
/>
```

## Custom Separator

Le séparateur se personnalise via l'input `separator` (chaîne) ou, pour un contenu riche,
via le template `#separator` :

<Canvas of={BreadcrumbStories.CustomSeparator} />

```html
<ui-breadcrumb [items]="items">
  <ng-template #separator>
    <ui-icon name="chevron-right" size="sm" />
  </ng-template>
</ui-breadcrumb>
```

## Ellipsis

Une ellipse peut indiquer des éléments masqués : au-delà de `maxItems`, le milieu du fil
se replie derrière un **bouton** ellipsis (premier élément + « … » + éléments de fin).
L'activer révèle les éléments masqués et déplace le focus sur le premier élément révélé ,
les pages intermédiaires restent atteignables au clavier et au lecteur d'écran.

<Canvas of={BreadcrumbStories.Ellipsis} />

```html
<ui-breadcrumb [items]="items" [maxItems]="3" />
```

## Custom Item

Le contenu des éléments se personnalise via le template `#item` (contexte : `$implicit` =
item, `last`) , par exemple pour rendre la page courante en texte simple :

<Canvas of={BreadcrumbStories.CustomItem} />

```html
<ui-breadcrumb [items]="items">
  <ng-template #item let-item let-last="last">
    @if (!last) {
      <ui-link [label]="item.label" [href]="item.url" size="small" />
    } @else {
      <span class="current">{{ item.label }}</span>
    }
  </ng-template>
</ui-breadcrumb>
```

## Accessibilité

<table className="doc-table">
  <thead>
    <tr>
      <th>Règle</th>
      <th>Détail</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>Landmark</strong></td>
      <td>Racine <code>&lt;nav&gt;</code> nommée par <code>ariaLabel</code> (défaut « Fil d'Ariane ») , repérable par les lecteurs d'écran.</td>
    </tr>
    <tr>
      <td><strong>Liste ordonnée</strong></td>
      <td>Les éléments sont des <code>&lt;li&gt;</code> d'une <code>&lt;ol&gt;</code> : la hiérarchie est annoncée avec son ordre et son nombre d'éléments.</td>
    </tr>
    <tr>
      <td><strong>Séparateurs</strong></td>
      <td>Purement décoratifs : <code>aria-hidden="true"</code>, ignorés par les lecteurs d'écran.</td>
    </tr>
    <tr>
      <td><strong>Page courante</strong></td>
      <td>Le dernier élément porte <code>aria-current="page"</code>. Sans destination, il est rendu en texte simple (<code>._current</code>) plutôt qu'en lien inerte.</td>
    </tr>
    <tr>
      <td><strong>Élément natif</strong></td>
      <td>Une destination donne une ancre avec <code>href</code>, une <code>command</code> seule un <code>&lt;button&gt;</code> : jamais d'ancre sans <code>href</code> ni de <code>&lt;span&gt;</code> cliquable.</td>
    </tr>
    <tr>
      <td><strong>Liens externes</strong></td>
      <td><code>target="_blank"</code> pose automatiquement <code>rel="noopener noreferrer"</code> (surchargeable via <code>rel</code>).</td>
    </tr>
    <tr>
      <td><strong>Désactivé</strong></td>
      <td>Un élément <code>disabled</code> perd son ancre : hors séquence de tabulation, non cliquable, aucun <code>itemClick</code>.</td>
    </tr>
    <tr>
      <td><strong>Clavier</strong></td>
      <td>Aucune interaction spécifique : les liens (et le bouton ellipsis) suivent la séquence de tabulation naturelle de la page.</td>
    </tr>
    <tr>
      <td><strong>Ellipsis</strong></td>
      <td><code>&lt;button&gt;</code> natif nommé (<code>ellipsisAriaLabel</code>) + <code>aria-expanded</code> ; l'activation révèle les éléments et déplace le focus sur le premier révélé.</td>
    </tr>
    <tr>
      <td><strong>Icon-only</strong></td>
      <td>Un élément icône sans label (accueil) doit fournir <code>ariaLabel</code> , un garde-fou avertit en console en mode dev.</td>
    </tr>
  </tbody>
</table>
