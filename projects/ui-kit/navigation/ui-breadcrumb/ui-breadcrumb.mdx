## Basic

The current position in the hierarchy: the last item represents the current page
(<code>aria-current="page"</code>) and typically has no destination.

```html
<ui-breadcrumb
  [items]="[
    { icon: 'house', ariaLabel: 'Home', url: '/' },
    { label: 'Electronics', url: '/electronics' },
    { label: 'Wireless keyboard' },
  ]"
/>
```

## Route

The breadcrumb is used with the Angular router to navigate between pages: `routerLink`
(string or array of segments) switches each item to the `RouterLink` directive
(SPA navigation, native anchor behavior preserved). `queryParams` and `fragment`
are passed through to the directive.

<Canvas of={BreadcrumbStories.Route} />

```html
<ui-breadcrumb
  [items]="[
    { icon: 'house', ariaLabel: 'Home', routerLink: '/' },
    { label: 'Catalog', routerLink: '/catalog', queryParams: { sort: 'price' } },
    { label: 'Wireless keyboard' },
  ]"
/>
```

## Links

Each item renders its anchor directly — no intermediate component — so a link's
attributes stay accessible item by item:

<table className="doc-table">
  <thead>
    <tr>
      <th>Case</th>
      <th>Render</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>url</code> (+ <code>target</code>, <code>rel</code>)</td>
      <td><code>&lt;a href&gt;</code>. <code>rel</code> defaults to <code>noopener noreferrer</code> as soon as <code>target="_blank"</code>.</td>
    </tr>
    <tr>
      <td><code>routerLink</code> (+ <code>queryParams</code>, <code>fragment</code>, <code>target</code>)</td>
      <td><code>&lt;a&gt;</code> driven by <code>RouterLink</code> — takes priority over <code>url</code>.</td>
    </tr>
    <tr>
      <td><code>command</code> with no destination</td>
      <td><code>&lt;button type="button"&gt;</code>: an action isn't a link (correct keyboard support + role).</td>
    </tr>
    <tr>
      <td>no destination, or <code>disabled</code></td>
      <td><code>&lt;span&gt;</code>: never an anchor with no <code>href</code> (neither focusable nor announced as a link).</td>
    </tr>
  </tbody>
</table>

<Canvas of={BreadcrumbStories.Links} />

```html
<ui-breadcrumb
  [items]="[
    { icon: 'house', ariaLabel: 'Home', routerLink: '/' },
    { label: 'Documentation', url: 'https://example.com/docs', target: '_blank' },
    { label: 'Back', command: onBack },
    { label: 'Archived', url: '/archive', disabled: true },
    { label: 'Current page' },
  ]"
/>
```

## Custom Separator

The separator is customized via the `separator` input (string) or, for rich content,
via the `#separator` template:

<Canvas of={BreadcrumbStories.CustomSeparator} />

```html
<ui-breadcrumb [items]="items">
  <ng-template #separator>
    <ui-icon name="chevron-right" size="sm" />
  </ng-template>
</ui-breadcrumb>
```

## Ellipsis

An ellipsis can indicate hidden items: past `maxItems`, the middle of the breadcrumb
collapses behind an **ellipsis button** (first item + "…" + trailing items).
Activating it reveals the hidden items and moves focus to the first revealed item;
the intermediate pages stay reachable by keyboard and screen reader.

<Canvas of={BreadcrumbStories.Ellipsis} />

```html
<ui-breadcrumb [items]="items" [maxItems]="3" />
```

## Custom Item

An item's content is customized via the `#item` template (context: `$implicit` =
item, `last`), for example to render the current page as plain text:

<Canvas of={BreadcrumbStories.CustomItem} />

```html
<ui-breadcrumb [items]="items">
  <ng-template #item let-item let-last="last">
    @if (!last) {
      <ui-link [label]="item.label" [href]="item.url" size="small" />
    } @else {
      <span class="current">{{ item.label }}</span>
    }
  </ng-template>
</ui-breadcrumb>
```

## Accessibility

<table className="doc-table">
  <thead>
    <tr>
      <th>Rule</th>
      <th>Detail</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>Landmark</strong></td>
      <td>Root <code>&lt;nav&gt;</code> named by <code>ariaLabel</code> (default "Breadcrumb"), discoverable by screen readers.</td>
    </tr>
    <tr>
      <td><strong>Ordered list</strong></td>
      <td>Items are <code>&lt;li&gt;</code>s of an <code>&lt;ol&gt;</code>: the hierarchy is announced with its order and item count.</td>
    </tr>
    <tr>
      <td><strong>Separators</strong></td>
      <td>Purely decorative: <code>aria-hidden="true"</code>, ignored by screen readers.</td>
    </tr>
    <tr>
      <td><strong>Current page</strong></td>
      <td>The last item carries <code>aria-current="page"</code>. With no destination, it is rendered as plain text (<code>._current</code>) rather than as an inert link.</td>
    </tr>
    <tr>
      <td><strong>Native element</strong></td>
      <td>A destination yields an anchor with <code>href</code>, a lone <code>command</code> a <code>&lt;button&gt;</code>: never an anchor with no <code>href</code> nor a clickable <code>&lt;span&gt;</code>.</td>
    </tr>
    <tr>
      <td><strong>External links</strong></td>
      <td><code>target="_blank"</code> automatically sets <code>rel="noopener noreferrer"</code> (overridable via <code>rel</code>).</td>
    </tr>
    <tr>
      <td><strong>Disabled</strong></td>
      <td>A <code>disabled</code> item loses its anchor: out of tab order, not clickable, no <code>itemClick</code>.</td>
    </tr>
    <tr>
      <td><strong>Keyboard</strong></td>
      <td>No specific interaction: the links (and the ellipsis button) follow the page's natural tab order.</td>
    </tr>
    <tr>
      <td><strong>Ellipsis</strong></td>
      <td>Native named <code>&lt;button&gt;</code> (<code>ellipsisAriaLabel</code>) + <code>aria-expanded</code>; activating it reveals the items and moves focus to the first revealed one.</td>
    </tr>
    <tr>
      <td><strong>Icon-only</strong></td>
      <td>An icon item with no label (home) must provide <code>ariaLabel</code>; a guard warns in the console in dev mode.</td>
    </tr>
  </tbody>
</table>
