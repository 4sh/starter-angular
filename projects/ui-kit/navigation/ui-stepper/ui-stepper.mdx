# ui-stepper

**Headless** progress wizard: guides the user through numbered steps
(multi-step form, funnel, wizard). **Composition** API — a
`ui-stepper` container drives the state, a list of `ui-step` headers, and
`ui-step-panel` panels paired to each step by their `value`.

### ui-step-item

**Vertical** layout wrapper: a (required) `value` propagated to the `ui-step` and
`ui-step-panel` it contains.

## Horizontal

Combining `ui-step-list` (header row) and `ui-step-panels` (panels
below). Each `ui-step` and the `ui-step-panel` of the same `value` form a
pair; the container's `value` determines the active step.

<Canvas of={StepperStories.Basic} />

## Vertical

The vertical layout requires a `ui-step-item` wrapping a `ui-step` and
its `ui-step-panel`. The active panel **unfolds** (collapse) under its header,
along the connecting rail, while the others fold back — animation driven
by `[motion]` via the shared motion system (`prefers-reduced-motion` /
`data-motion="off"` respected).

<Canvas of={StepperStories.Vertical} />

## Linear

With `linear`, the current step must be completed before moving to the next:
steps **after** the active one are disabled (no jumping ahead). Progress is
driven by setting `value` (a "Continue" button in the panel, or the
`next()`/`prev()` methods). Already-completed steps stay clickable to go
back.

<Canvas of={StepperStories.Linear} />

## Steps only

A `ui-step-list` **with no panels**: a simple progress indicator. Useful
to visualize progress when the content lives elsewhere.

<Canvas of={StepperStories.StepsOnly} />

## Rich content (template)

Panels accept free markup and library components
(`ui-tag`, `ui-button`…). `completedIcon` replaces the number of completed steps
with an icon (here `check`), and `icon` on a `ui-step` sets the marker's glyph.

<Canvas of={StepperStories.Template} />

## Controlled

The active step is driven from the outside via the two-way `[(value)]` model.

## Accessibility

<table className="doc-table">
  <thead>
    <tr><th>Point</th><th>Implementation</th></tr>
  </thead>
  <tbody>
    <tr>
      <td>ARIA structure</td>
      <td>The header container carries `role="tablist"` (`ui-step-list` in horizontal, the `ui-stepper` host in vertical) with `aria-orientation`; `aria-label` (via `ariaLabel`) describes the progress.</td>
    </tr>
    <tr>
      <td>Headers</td>
      <td>Each header is a native `&lt;button role="tab"&gt;`, with `aria-controls` pointing to its panel, `aria-selected` and `aria-current="step"` on the active step.</td>
    </tr>
    <tr>
      <td>Panels</td>
      <td>Each panel has `role="tabpanel"`, an `id` matching its header's `aria-controls`, and `aria-labelledby` pointing to that header; an inactive panel stays in the DOM but is `hidden`.</td>
    </tr>
    <tr>
      <td>Keyboard — <kbd>Tab</kbd></td>
      <td>Moves focus through the headers (each activatable header is a native stop; disabled steps are skipped).</td>
    </tr>
    <tr>
      <td>Keyboard — <kbd>Enter</kbd> / <kbd>Space</kbd></td>
      <td>Activates the focused header (native `&lt;button&gt;` behavior).</td>
    </tr>
    <tr>
      <td>Decorative marker</td>
      <td>The marker's number / icon is `aria-hidden`; meaning comes from the step's title, not only from color.</td>
    </tr>
    <tr>
      <td>Visible focus</td>
      <td>`:focus-visible` draws a ring around the marker, distinct from `:hover`.</td>
    </tr>
    <tr>
      <td>Disabled</td>
      <td>Native `disabled` (not just visual): colors via the `-disabled` tokens.</td>
    </tr>
    <tr>
      <td>Motion</td>
      <td>The collapse/expand (`grid-rows` collapse) and the panel fade are neutralized under `prefers-reduced-motion`, `data-motion="off"` and `[motion]="false"`.</td>
    </tr>
  </tbody>
</table>

## Examples

```html
<!-- Horizontal -->
<ui-stepper [(value)]="active">
  <ui-step-list ariaLabel="Steps">
    <ui-step [value]="1">Account</ui-step>
    <ui-step [value]="2">Profile</ui-step>
    <ui-step [value]="3">Confirmation</ui-step>
  </ui-step-list>
  <ui-step-panels>
    <ui-step-panel [value]="1">…</ui-step-panel>
    <ui-step-panel [value]="2">…</ui-step-panel>
    <ui-step-panel [value]="3">…</ui-step-panel>
  </ui-step-panels>
</ui-stepper>

<!-- Vertical (ui-step-item wraps the step and its panel) -->
<ui-stepper [(value)]="active" orientation="vertical" ariaLabel="Installation">
  <ui-step-item [value]="1">
    <ui-step [value]="1">Prerequisites</ui-step>
    <ui-step-panel [value]="1">…</ui-step-panel>
  </ui-step-item>
  <ui-step-item [value]="2">
    <ui-step [value]="2">Configuration</ui-step>
    <ui-step-panel [value]="2">…</ui-step-panel>
  </ui-step-item>
</ui-stepper>

<!-- Linear + completion icon -->
<ui-stepper [(value)]="active" [linear]="true" completedIcon="check"> … </ui-stepper>

<!-- Steps only (progress indicator) -->
<ui-stepper [value]="2">
  <ui-step-list ariaLabel="Progress">
    <ui-step [value]="1">Quote</ui-step>
    <ui-step [value]="2">Approval</ui-step>
    <ui-step [value]="3">Delivery</ui-step>
  </ui-step-list>
</ui-stepper>
```
