# ui-tabs

**Headless** tabs: switches between several views. **Composition** API — a
`ui-tabs` container drives the state, a `ui-tab-list` of `ui-tab`s,
and a `ui-tab-panels` grouping the `ui-tab-panel`s. Each tab and its panel
are paired by their `value`.

100% driven by the **design tokens** (`navigation.*` for the list, `global` for
the content). The active tab indicator slides, and each panel fades in,
via the shared **motion system**, which automatically respects
`prefers-reduced-motion` and the global `data-motion="off"` switch.

## Scrolling

`scrollable` turns the list into a scrollable area; the **previous /
next** buttons (`showNavigators`, visible by default) appear when the list
overflows.

<Canvas of={TabsStories.Scrollable} />

## Activate on focus

With `selectOnFocus`, moving keyboard focus (arrow keys) **activates** the tab
along the way (automatic activation, WAI-ARIA Tabs pattern). Otherwise, activation
stays manual (`Enter` / `Space`).

<Canvas of={TabsStories.SelectOnFocus} />

## Lazy loading

By default an inactive tab's content is **rendered** (but hidden). `lazy` (on
`ui-tabs` for the whole group, or on a `ui-tab-panel`) only renders the content
**on first activation**. To only initialize complex components at that
moment, wrap the content in `<ng-template #content>…</ng-template>`.

<Canvas of={TabsStories.Lazy} />

## Accessibility

<table className="doc-table">
  <thead>
    <tr><th>Point</th><th>Implementation</th></tr>
  </thead>
  <tbody>
    <tr>
      <td>Native buttons</td>
      <td>Each tab is a native `&lt;button role="tab"&gt;` (the `ui-tab` host is `display: contents`), so focusable and actionable by keyboard; native `disabled`.</td>
    </tr>
    <tr>
      <td>ARIA structure</td>
      <td>`role="tablist"` (with `aria-orientation`) → `role="tab"` (`aria-selected`, `aria-controls`) → `role="tabpanel"` (`aria-labelledby` pointing to its tab, `tabindex="0"`).</td>
    </tr>
    <tr>
      <td>Keyboard</td>
      <td>`←`/`→` (horizontal) or `↑`/`↓` (vertical) move focus between tabs (roving, wraps around); `Home`/`End` to the first/last; `Enter`/`Space` activate. `selectOnFocus` activates on move.</td>
    </tr>
    <tr>
      <td>Single tab stop</td>
      <td>Only the active tab (or the first available) is in tab order (roving `tabindex`); the others are reached with the arrow keys.</td>
    </tr>
    <tr>
      <td>Hidden panel</td>
      <td>An inactive panel stays in the DOM but is `hidden` (state preserved, invisible to screen readers).</td>
    </tr>
    <tr>
      <td>Decorative icon</td>
      <td>`ui-icon` set to `aria-hidden`; meaning comes from the label, not only from the icon.</td>
    </tr>
    <tr>
      <td>Motion</td>
      <td>Indicator and fade neutralized under `prefers-reduced-motion`, `data-motion="off"` and `[motion]="false"`.</td>
    </tr>

## Examples

```html
<!-- Basic -->
<ui-tabs [(value)]="active">
  <ui-tab-list ariaLabel="Sections">
    <ui-tab [value]="0">Overview</ui-tab>
    <ui-tab [value]="1">Activity</ui-tab>
  </ui-tab-list>
  <ui-tab-panels>
    <ui-tab-panel [value]="0">Content 1…</ui-tab-panel>
    <ui-tab-panel [value]="1">Content 2…</ui-tab-panel>
  </ui-tab-panels>
</ui-tabs>

<!-- Vertical + scrollable + lazy loading -->
<ui-tabs [(value)]="active" orientation="vertical" [scrollable]="true" [lazy]="true"> … </ui-tabs>

<!-- Navigation menu (tabs only + router-outlet) -->
<ui-tabs [value]="url">
  <ui-tab-list ariaLabel="Navigation">
    <ui-tab [value]="'/dashboard'" icon="gauge">Dashboard</ui-tab>
    <ui-tab [value]="'/team'" icon="users">Team</ui-tab>
  </ui-tab-list>
</ui-tabs>
<router-outlet />
```
