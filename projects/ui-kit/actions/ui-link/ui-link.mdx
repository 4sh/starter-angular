# ui-link

**Inline text** link: a real `<a>`, meant for the flow of text (paragraphs) and
navigation. Styled with the subdued `actions.low.content.*` family (light **and** dark tokens).

> **Choose by semantics, not by appearance.**
> - What **navigates** (URL / route) → `ui-link`, or `ui-button` with `href`/`routerLink`
>   when the appearance of a button is needed.
> - What **triggers an action** (submit, open a modal…) → `ui-button`.

Accepts an external destination (`href`) **or** an internal one (`routerLink`, Angular directive).

## External link

`external` forces `target="_blank"` and sets a safe `rel="noopener noreferrer"`.

<Canvas of={LinkStories.External} />

## Internal navigation (RouterLink)

`routerLink` switches to the Angular directive for SPA navigation (the anchor's
native behavior — Cmd/Ctrl+click, etc. — is preserved).

<Canvas of={LinkStories.RouterInternal} />

```html
<ui-link label="My profile" [routerLink]="['/profile']" iconRight="chevron-right" />
```

## Accessibility

<table className="doc-table">
  <thead>
    <tr>
      <th>Rule</th>
      <th>Detail</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>Semantics</strong></td>
      <td>Native <code>&lt;a&gt;</code>. A link navigates; for an action, use <code>ui-button</code>.</td>
    </tr>
    <tr>
      <td><strong>Underline</strong></td>
      <td>Underlined by default: color is never the sole cue of an inline link. Removed in <em>icon-only</em> mode.</td>
    </tr>
    <tr>
      <td><strong>Labeling</strong></td>
      <td><code>aria-label</code> set when useful (icon-only). A dev-mode warning flags an icon-only link with no accessible name.</td>
    </tr>
    <tr>
      <td><strong>External</strong></td>
      <td><code>external</code> / <code>target="_blank"</code> ⇒ automatic <code>rel="noopener noreferrer"</code>.</td>
    </tr>
    <tr>
      <td><strong>States</strong></td>
      <td><code>:focus-visible</code> visible and distinct from <code>hover</code>. <code>disabled</code>: href/routerLink removed, <code>aria-disabled</code>, out of tab order (<code>tabindex=-1</code>).</td>
    </tr>
    <tr>
      <td><strong>Context</strong></td>
      <td><code>ariaCurrent</code> sets <code>aria-current</code> on the anchor (e.g. <code>"page"</code> for a breadcrumb's current item — used by <code>ui-breadcrumb</code>).</td>
    </tr>
