# ui-button-split

A main **action button** joined to a **dropdown trigger** that reveals
a collection of additional options. The composition logic reuses
[`ui-button`](?path=/docs/components-ui-actions-ui-button--docs) (both buttons,
`actions.*` tokens) and [`ui-menu`](?path=/docs/components-ui-navigation-ui-menu--docs)
(the panel, `navigation.*` tokens). Options are driven by a
declarative `UiMenuItem[]` model — the same one the menu uses.

## API

<ArgTypes of={ButtonSplitStories} />

## Basic

The action button triggers the default action (`buttonClick`); the trigger
opens a menu of additional options defined by the `model` property, based on
the `UiMenuItem` model.

```html
<ui-button-split label="Save" [model]="options" (buttonClick)="save()" (itemClick)="onOption($event)" />
```

## Icons

Both the buttons and the menu options support showing icons.

```html
<ui-button-split label="Save" icon="floppy-disk" [model]="optionsWithIcons" />
```

<Canvas of={ButtonSplitStories.Icons} />

## Nested

Options can nest into submenus (collapsible groups), still via the
`UiMenuItem` model (an item with `items` becomes a group).

<Canvas of={ButtonSplitStories.Nested} />

## Level

The `level` property defines the button type.

<Canvas of={ButtonSplitStories.Level} />

## Disabled

With the `disabled` attribute, the component is inactive and not focusable. The
disabled states of the button and the trigger can also be managed independently: the
action button is disabled via `buttonDisabled`, the menu trigger via
`menuButtonDisabled`.
