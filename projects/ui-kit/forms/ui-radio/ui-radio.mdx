## Groups & forms

Each <code>ui-radio</code> carries a <code>value</code>; the group forms by linking every
member **to the same control** (same <code>[formField]</code>, same <code>formControlName</code> or
same <code>[(ngModel)]</code>) **and** giving them the same <code>name</code> (native grouping
→ arrow-key navigation). The radio whose <code>value</code> equals the model's value is
selected. The component is a <code>ControlValueAccessor</code>: it wires up with no extra code
to **Signal Forms** (`@angular/forms/signals`, `[formField]` directive, stable since
Angular 22) via native CVA interop, as well as to template-driven and reactive forms.

<Canvas of={RadioStories.SignalForms} />

```html
<!-- Signal Forms: each member linked to the same [formField] -->
<div role="radiogroup" aria-label="Flavor">
  <ui-radio [formField]="flavor" name="flavor" value="vanilla" label="Vanilla" />
  <ui-radio [formField]="flavor" name="flavor" value="chocolate" label="Chocolate" />
</div>

<!-- Template-driven -->
<div role="radiogroup" aria-label="Flavor">
  <ui-radio [(ngModel)]="flavor" name="flavor" value="vanilla" label="Vanilla" />
  <ui-radio [(ngModel)]="flavor" name="flavor" value="chocolate" label="Chocolate" />
</div>

<!-- Reactive: each member linked to the same formControlName -->
<div role="radiogroup" aria-label="Plan" formGroupName="subscription">
  <ui-radio formControlName="plan" name="plan" value="free" label="Free" />
  <ui-radio formControlName="plan" name="plan" value="pro" label="Pro" />
</div>
```

> ⚠️ **Template-driven limitation inside a `<form>`**: each `ui-radio` is an
> *independent* CVA (no shared registry like native `<input type=radio>`s).
> Inside a `<form>` (NgForm), several `[(ngModel)]`s carrying the same
> `name` trigger Angular's "more than one control with the same
> name" error. In that case, use reactive forms / Signal Forms, or
> `[ngModelOptions]="{ standalone: true }"` on each member. `[(ngModel)]`
> outside a `<form>` (example above) works with no restriction.

- The **error style applies automatically** when the attached control is invalid **and**
  touched/dirty; `invalid` lets you force it.
- `disabled` per member (grays out an option) or via `control.disable()` (the whole group).
- `value` accepts any type (`T`), not just strings.

    <tr>
      <td><strong>Labeling</strong></td>
