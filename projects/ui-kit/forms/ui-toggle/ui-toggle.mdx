## Label position

The label sits on the right (`after`, default) or the left (`before`) of the switch. Since the whole
thing is wrapped in a native `<label>`, **clicking the label on either side toggles the switch**.

<Canvas of={ToggleStories.LabelBefore} />

## Custom handle

A `handle` template (context `{ checked }`) replaces the handle's content — for example a
`check` / `xmark` icon depending on the state.

<Canvas of={ToggleStories.CustomHandle} />

```html
<ng-template #handle let-checked="checked">
  <ui-icon [name]="checked ? 'check' : 'xmark'" size="sm" />
</ng-template>

<ui-toggle [(ngModel)]="darkMode" [handle]="handle" label="Dark mode" />
```

## Forms

Wired into the starter's form system via `ControlValueAccessor`
(`BaseControlValueAccessor`): works with **Signal Forms** (`@angular/forms/signals`,
`[formField]` directive, stable since Angular 22) via native CVA interop, with
`[(ngModel)]`, reactive forms (`formControlName`) or standalone. The error state paints
automatically when the attached control is invalid **and** touched/dirty.

```html
<!-- Signal Forms -->
<ui-toggle [formField]="notifications" label="Notifications" />

<!-- Reactive forms -->
<ui-toggle formControlName="darkMode" label="Dark mode" />

<!-- ngModel -->
<ui-toggle [(ngModel)]="notifications" label="Notifications" />

<!-- Custom values -->
<ui-toggle [(ngModel)]="status" trueValue="on" falseValue="off" label="Status" />
```
