# ui-input-number

**Numeric** field built on the [`ui-field`](?path=/docs/components-ui-forms-ui-field--docs) shell.
Model value = `number | null`. Tolerant input (no reformatting while typing →
no cursor jump), `min`/`max`/`step`, ± spinner and ↑/↓ arrow keys, **clamp on blur**.

Standalone, `[(ngModel)]`, reactive forms or Signal Forms (`[formField]`).

## Formatting (Intl.NumberFormat)

The rich format (thousands grouping, currency, decimals) is applied **on blur**; on
focus, the field switches to an editable form (no grouping/currency) for smooth typing.
Driven by `locale` / `currency` / `useGrouping` / `minFractionDigits` / `maxFractionDigits`.

## Forms

The component is a `ControlValueAccessor`: it wires up with no extra code to
**Signal Forms** (`@angular/forms/signals`, `[formField]` directive, stable since
Angular 22) via native CVA interop, as well as to template-driven
(`[(ngModel)]`) and reactive (`[formControl]`) forms.

<Canvas of={NumberStories.SignalForms} />

```html
<!-- Signal Forms -->
<ui-input-number [formField]="quantity" label="Rating (0–10)" [min]="0" [max]="10" />

<!-- Template-driven -->
<ui-input-number [(ngModel)]="price" label="Price" locale="en-US" currency="USD" [step]="0.5" />

<!-- Reactive -->
<ui-input-number [formControl]="ageCtrl" label="Age" [min]="0" [max]="120" [allowDecimals]="false" />
```
