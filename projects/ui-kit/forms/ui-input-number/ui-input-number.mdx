# ui-input-number

Champ **numérique** bâti sur le shell [`ui-field`](?path=/docs/components-ui-forms-ui-field--docs).
Valeur modèle = `number | null`. Saisie tolérante (pas de reformatage pendant la frappe →
pas de saut de curseur), `min`/`max`/`step`, spinner ± et flèches clavier ↑/↓, **clamp au blur**.

Autonome, `[(ngModel)]`, reactive forms ou Signal Forms (`[formField]`).

## Libellé flottant

`floatLabel` fait descendre le libellé **dans** le champ, où il tient le rôle du placeholder,
et le fait remonter au focus ou dès que le champ porte une valeur. Trois positions hautes :
`over` (au-dessus de la boîte), `in` (dans une bande réservée en haut de la boîte, qui grandit
d'autant) et `on` (à cheval sur le trait, qu'il entaille). Le `placeholder` est neutralisé tant
que `floatLabel` et `label` sont tous les deux renseignés : les deux textes se superposeraient.

En variante `in`, le spinner garde toute la hauteur de la boîte et l'unité y reste centrée :
seule la valeur saisie descend sous la bande du libellé.

<Canvas of={NumberStories.FloatLabel} />

Le mécanisme est celui du shell partagé `ui-field`, commun à tous les champs à boîte : détail
des trois variantes, du déclenchement et des conséquences de mise en page sur [`ui-input`](?path=/docs/components-ui-forms-ui-input--docs).

## Formatage (Intl.NumberFormat)

Le format riche (groupement des milliers, devise, décimales) est appliqué **au blur** ; au
focus, le champ bascule sur une forme éditable (sans groupement/devise) pour une saisie fluide.
Piloté par `locale` / `currency` / `useGrouping` / `minFractionDigits` / `maxFractionDigits`.

## Formulaires

Le composant est un `ControlValueAccessor` : il se branche sans code additionnel aux
**Signal Forms** (`@angular/forms/signals`, directive `[formField]`, stables depuis
Angular 22) via l'interop CVA native, ainsi qu'aux formulaires template-driven
(`[(ngModel)]`) et réactifs (`[formControl]`).

<Canvas of={NumberStories.SignalForms} />

```html
<!-- Signal Forms -->
<ui-input-number [formField]="quantity" label="Note (0–10)" [min]="0" [max]="10" />

<!-- Template-driven -->
<ui-input-number [(ngModel)]="price" label="Prix" locale="fr-FR" currency="EUR" [step]="0.5" />

<!-- Reactive -->
<ui-input-number [formControl]="ageCtrl" label="Âge" [min]="0" [max]="120" [allowDecimals]="false" />
```
