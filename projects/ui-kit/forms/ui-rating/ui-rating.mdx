# ui-rating

The `ui-rating` component lets the user give a rating on a scale (5 stars by default). It's built on an invisible `<input type="range">`, guaranteeing native accessibility (keyboard, screen reader, form).

<Canvas of={UiRatingStories.Default} />

## API

<ArgTypes />

### Half stars

`allowHalf` switches the selection step to **0.5**: clicking the front half of a
star sets the half rating, clicking the back half sets the whole star, and the
keyboard arrows advance by 0.5 increments (the underlying `<input type="range">`'s `step` follows
suit). `cancel` still works on the exact value: re-clicking the same half resets to `null`.

<Canvas of={UiRatingStories.AllowHalf} />

The partial fill relies on no dedicated icon: the "on" icon is **layered**
over the "off" icon then clipped (`clip-path`) to the desired fraction. The half star
therefore works as-is with any icon family and with the projected
`#onIcon` / `#offIcon` templates, in LTR as well as RTL.

<Canvas of={UiRatingStories.HalfReadonly} />

## Forms

The component is a `ControlValueAccessor`: it wires up with no extra code to
**Signal Forms** (`@angular/forms/signals`, `[formField]` directive, stable since
Angular 22) via native CVA interop, as well as to template-driven
(`[(ngModel)]`) and reactive (`[formControl]`) forms.

> ℹ️ **"Not rated" value = `null`** (type `number | null`): `cancel`
> (re-clicking the current rating) and the keyboard reset both emit `null`,
> and `writeValue(null)` is preserved — `Validators.required` (or `required()` in
> Signal Forms) therefore naturally rejects a missing rating, with no `min(1)`
> workaround. *(Breaking: earlier versions emitted the `0` sentinel.)*

<Canvas of={UiRatingStories.SignalForms} />

```html
<!-- Signal Forms -->
<ui-rating [formField]="rating" ariaLabel="Rating" />

<!-- Template-driven -->
<ui-rating [(ngModel)]="note" ariaLabel="Rating" />

<!-- Reactive -->
<ui-rating [formControl]="noteCtrl" ariaLabel="Rating" />
```
