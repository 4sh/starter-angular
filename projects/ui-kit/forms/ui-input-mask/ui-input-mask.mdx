# ui-input-mask

Champ **masqué** bâti sur le shell [`ui-field`](?path=/docs/components-ui-forms-ui-field--docs).
Le gabarit `mask` insère automatiquement les littéraux pendant la frappe :

  <thead>
    <tr>
      <th>Token</th>
      <th>Accepte</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>9</code></td>
      <td>un chiffre <code>0-9</code></td>
    </tr>
    <tr>
      <td><code>a</code></td>
      <td>une lettre <code>a-z A-Z</code></td>
    </tr>
    <tr>
      <td><code>*</code></td>
      <td>un caractère alphanumérique</td>
    </tr>

      <td><em>autre</em></td>

    </tr>
  </tbody>
</table>

Valeur modèle = string masquée (`12/09/2024`) par défaut, ou brute (`12092024`) si `unmask`.

## Valeurs bornées (`ranges`)

Le masque décrit la **forme**. L'input `ranges` borne
chaque **segment numérique** — une suite de tokens `9` consécutifs — dans l'**ordre du masque**,
sous forme de `min-max` séparés par des espaces (`*` laisse un segment libre) :

<table className="doc-table">
  <thead>
    <tr><th>Masque</th><th><code>ranges</code></th><th>Effet</th></tr>
  </thead>
  <tbody>
    <tr>
      <td><code>99:99</code></td>
      <td><code>0-23 0-59</code></td>
      <td>heure 24 h — <code>33:33</code> devient impossible à saisir</td>
    </tr>
    <tr>
      <td><code>99/99/9999</code></td>
      <td><code>1-31 1-12 1900-2100</code></td>
      <td>jour / mois / année</td>
    </tr>
    <tr>
      <td><code>99:99:99</code></td>
      <td><code>* 0-59 0-59</code></td>
      <td>seuls les 2ᵉ et 3ᵉ segments sont bornés</td>
    </tr>
  </tbody>
</table>

Le contrôle se fait **à la frappe**, par anticipation : un caractère n'est accepté que s'il reste
au moins une façon de compléter le segment dans la plage. Sur `0-23`, `3` est refusé d'emblée
(`30`-`39` sortent tous de la plage) ; `2` passe, puis `4` est refusé et `3` accepté. Un segment
**entièrement rempli** est donc toujours dans sa plage — la borne inférieure reste, elle,
atteignable par préfixe (`0` est accepté sur `1-31`, en attente du `1`-`9` suivant).

<Canvas of={MaskStories.Time} />

> `ranges` ne borne que les segments **numériques** (`9`) ; les tokens `a`/`*` sont ignorés dans la
> numérotation. Les bornes s'appliquent aussi aux valeurs **écrites par le formulaire**
> (`writeValue`), comme le filtrage de caractères déjà en place. Un segment **incomplet**
> (`9_:__`) reste possible : la complétude relève de la validation du formulaire (`required`, ou un
> validateur dédié), pas du masque.

## Libellé flottant

`floatLabel` fait descendre le libellé **dans** le champ, où il tient le rôle du placeholder,
et le fait remonter au focus ou dès que le champ porte une valeur. Trois positions hautes :
`over` (au-dessus de la boîte), `in` (dans une bande réservée en haut de la boîte, qui grandit
d'autant) et `on` (à cheval sur le trait, qu'il entaille). Le `placeholder` est neutralisé tant
que `floatLabel` et `label` sont tous les deux renseignés : les deux textes se superposeraient.


<Canvas of={MaskStories.FloatLabel} />

Le mécanisme est celui du shell partagé `ui-field`, commun à tous les champs à boîte : détail
des trois variantes, du déclenchement et des conséquences de mise en page sur [`ui-input`](?path=/docs/components-ui-forms-ui-input--docs).

## Formulaires

Le composant est un `ControlValueAccessor` : il se branche sans code additionnel aux
**Signal Forms** (`@angular/forms/signals`, directive `[formField]`, stables depuis Angular 22)
via l'interop CVA native, ainsi qu'aux formulaires template-driven (`[(ngModel)]`) et réactifs
(`[formControl]`).

## Accessibilité & notes

<table className="doc-table">
  <thead>
    <tr><th>Point</th><th>Implémentation</th></tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>Label / aide / erreur</strong></td>
      <td>Via le shell `ui-field` : label lié par <code>for</code>/<code>id</code>, message relié par <code>aria-describedby</code>, <code>aria-invalid</code> en erreur.</td>
    </tr>
    <tr>
      <td><strong>Saisie</strong></td>
      <td>Les littéraux (`/`, `-`…) sont insérés automatiquement ; les caractères non conformes au token — ou hors des bornes <code>ranges</code> — sont ignorés.</td>
    </tr>
  </tbody>
</table>

```html
<!-- Signal Forms -->
<ui-input-mask [formField]="field" label="Date" mask="99/99/9999" placeholder="jj/mm/aaaa" />

<ui-input-mask formControlName="birthDate" label="Date" mask="99/99/9999" placeholder="jj/mm/aaaa" iconLeft="calendar" />
<ui-input-mask [(ngModel)]="phone" label="Téléphone" mask="(999) 999-9999" />
<ui-input-mask [(ngModel)]="iban" label="IBAN" mask="FR99 9999 9999 9999" [unmask]="true" />

<!-- Valeurs bornées -->
<ui-input-mask [(ngModel)]="time" label="Heure" mask="99:99" ranges="0-23 0-59" />
<ui-input-mask [(ngModel)]="birth" label="Date" mask="99/99/9999" ranges="1-31 1-12 1900-2100" />
```

> Caret : après masquage, le curseur est repositionné d'après le nombre de caractères de donnée
> situés avant lui (littéraux auto-insérés sautés) — l'édition **au milieu** de la chaîne conserve
> une position cohérente, pas seulement en fin de saisie.

## Theming

Aucune variable locale surchargeable : la boîte vient du shell `ui-field`. La configuration passe
par ses variables (groupe partagé [Forms](?path=/docs/components-configuration-forms--docs)),
détaillées sur la doc [`ui-input`](?path=/docs/components-ui-forms-ui-input--docs). Voir le
[fonctionnement de la configuration](?path=/docs/components-configuration--docs).
