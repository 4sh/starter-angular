# ui-nudger

The `ui-nudger` component is a compact **numeric stepper**: two icon-only
`ui-button`s (`−` / `+`) flanking the current value. It has no text
input, it's a pure step-by-step control, ideal for small quantities (cart, filters,
settings). The value is carried via `ControlValueAccessor`: standalone, `[(ngModel)]`,
Reactive Forms or Signal Forms.

## Bounds (min / max)

`min` and `max` bound the value. The relevant button is **disabled** as soon as the bound
is reached, so Figma's `Min` / `Max` states are **derived** from the value, never
from props (Angular idiom). The step is set by `step`.

## Variant

The `variant` input (`filled` by default, `outlined` · `ghost`) is forwarded to both
internal buttons, as is `onColor` (`dark` · `light`) when the nudger sits
on a colored background — see
[`ui-button`](?path=/docs/components-ui-actions-ui-button--docs).

## Value formatting

The `formatValue` input receives the numeric value and returns the displayed
string (unit, symbol, etc.).

<Canvas of={UiNudgerStories.Formatted} />

```html
<ui-nudger [(ngModel)]="weight" [min]="0" [formatValue]="(v) => v + ' kg'" ariaLabel="Weight" />
```

## Forms

The component is a `ControlValueAccessor`: it wires up with no extra code to
**Signal Forms** (`@angular/forms/signals`, `[formField]` directive, stable since
Angular 22) via native CVA interop, as well as to template-driven
(`[(ngModel)]`) and reactive (`[formControl]`) forms.

<Canvas of={UiNudgerStories.SignalForms} />

```html
<!-- Signal Forms -->
<ui-nudger [formField]="quantity" [min]="0" [max]="10" ariaLabel="Quantity" />

<!-- Template-driven -->
<ui-nudger [(ngModel)]="quantity" [min]="0" [max]="10" ariaLabel="Quantity" />

<!-- Reactive -->
<ui-nudger [formControl]="quantityCtrl" ariaLabel="Quantity" />
```
