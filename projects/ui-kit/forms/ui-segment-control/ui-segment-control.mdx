# ui-segment-control

Headless segmented control: a choice among a short list of inline segments
(or several with `multiple`). Each segment is a native `<button>`; the group
carries the WAI-ARIA semantics (`radiogroup`/`radio` in single mode with arrow-key
navigation and select-on-move, `group`/`aria-pressed` in `multiple` mode).
In single mode, a **sliding indicator** moves under the selected segment,
timed by the [motion system](?path=/docs/foundations-motion--docs) (respects
`prefers-reduced-motion` and the `motion` opt-out).

Works standalone, with `[(ngModel)]`, Reactive Forms, or Signal Forms (`[formField]`) —
it's a `ControlValueAccessor`.

## Options

Options accept three shapes:

```ts
// 1. Primitives — the value IS the label
options = ['List', 'Grid', 'Table'];

// 2. Objects { value, label?, icon?, disabled?, ariaLabel? }
options = [
  { value: 'list', label: 'List', icon: 'list' },
  { value: 'grid', label: 'Grid', icon: 'table-cells' },
];

// 3. Business objects + field mapping
options = [{ id: 1, name: 'List', off: false }];
// <ui-segment-control optionValue="id" optionLabel="name" optionDisabled="off" />
```

To compare **object** values during selection, supply `dataKey`
(e.g. `dataKey="id"`).

## Custom template

A segment's content is overridable via the `[itemTemplate]` input, which receives
`{ $implicit, option, selected, index }`.

```html
<ui-segment-control [(ngModel)]="plan" [options]="plans" [itemTemplate]="item" ariaLabel="Plan" />
<ng-template #item let-plan let-selected="selected">
  <strong>{{ plan.label }}</strong>
  <small>{{ plan.hint }}</small>
</ng-template>
```

## Icons

An option can carry an `icon` (with or without a `label`). In **icon-only**
mode (no `label`), an `ariaLabel` per segment is **required** (accessible name).

## Forms

The component is a `ControlValueAccessor`, so it wires up to every form
API with no extra code.

<Canvas of={SegmentStories.SignalForms} />
<Canvas of={SegmentStories.TemplateDriven} />
<Canvas of={SegmentStories.ReactiveForms} />

```html
<!-- Signal Forms -->
<ui-segment-control [formField]="color" [options]="colors" ariaLabel="Color" />

<!-- Template-driven -->
<ui-segment-control [(ngModel)]="view" name="view" [options]="views" ariaLabel="Display" />

<!-- Reactive -->
<ui-segment-control [formControl]="viewCtrl" [options]="views" ariaLabel="Display" />
```

- The **error style applies automatically** when the attached control is invalid
  **and** touched/dirty; `invalid` lets you force it.
- `disabled` disables the whole group (via the input or `control.disable()`);
  an object option's `disabled` grays out a single segment.
