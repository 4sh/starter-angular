# ui-input

**Text** field (text/email/tel/url/search/**password**) built on the shared
[`ui-field`](?path=/docs/components-ui-forms-ui-field--docs) shell (label + box + helper) and a
native `<input>`. Colors via `form.*` tokens, border driven by the `level`. Optional
slots: left icon, suffix unit, and a **right action zone**.

Standalone, `[(ngModel)]` or reactive forms (`ControlValueAccessor` via `BaseFormField`).
For numbers → [`ui-input-number`](?path=/docs/components-ui-forms-ui-input-number--docs);
for masks → [`ui-input-mask`](?path=/docs/components-ui-forms-ui-input-mask--docs).

field is in error (explicit `invalid`, or automatic: invalid control + touched).

## Slots & action zone

The right icon becomes an **action zone** (a square, full-height, focusable button) as soon as
`iconRightAriaLabel` is set; clicking it emits `iconRightClick`.

## Forms

The component is a `ControlValueAccessor`: it wires up with no extra code to
**Signal Forms** (`@angular/forms/signals`, `[formField]` directive, stable since Angular 22)
via native CVA interop, as well as to template-driven (`[(ngModel)]`) and reactive
(`[formControl]`) forms.

<Canvas of={InputStories.SignalForms} />

```html
<!-- Signal Forms -->
<ui-input [formField]="field" label="Name" placeholder="Your name" />
```

```html
<!-- Reactive forms + error message -->
<ui-input formControlName="email" type="email" label="Email" errorText="Invalid address" required />

<!-- Search: actionable "clear" icon, visible only with text -->
<ui-input
  [(ngModel)]="q"
  label="Search"
  iconLeft="magnifying-glass"
  [iconRight]="q ? 'xmark' : undefined"
  iconRightAriaLabel="Clear"
  (iconRightClick)="q = ''"
/>
```

> Architecture: `ui-input`, `ui-input-number` and `ui-input-mask` share the `ui-field` shell
> (label + box + helper + states) and the `BaseFormField` base (CVA + validation). The
> Figma subcomponent `_ui-input-content` is carried natively by the `<input>`.

## Theming

`ui-input`, `ui-input-mask` and `ui-input-number` have **no overridable local variable**:
their box is provided by the `ui-field` shell, styled via the `utils.field-*` mixins. The whole
configuration therefore goes through `ui-field.scss`'s local variables (which point to the shared
[Forms](?path=/docs/components-configuration-forms--docs) group). See also
[how configuration works](?path=/docs/components-configuration--docs).
