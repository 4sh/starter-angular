# ui-textarea

**Multiline** text area built on the shared
[`ui-field`](?path=/docs/components-ui-forms-ui-field--docs) shell (label + box + helper) in
**multiline** mode, with a native `<textarea>`. Colors via `form.*` tokens, border driven by the
`level`. Resizing via the browser's **native** handle (`resize`, vertical by default,
at the bottom-right corner) or `autoResize` (height follows the content). Optional character
counter (`showCount` + `maxlength`).

Standalone, `[(ngModel)]` or reactive forms (`ControlValueAccessor` via `BaseFormField`). For
single-line input → [`ui-input`](?path=/docs/components-ui-forms-ui-input--docs).

## Levels & states

`level` (`default`/`success`/`error`) drives the border. The `success` level is a **manual
visual** state (e.g. after a verification). The **error** state, on the other hand, is driven by validation:
the red border and `errorText` appear when the control is **invalid AND touched/dirty**
(the `showError` rule), and disappear as soon as the input becomes valid again.

## Validation

The component is a `ControlValueAccessor`: it wires up with no extra code to
**Signal Forms** (`@angular/forms/signals`, `[formField]` directive, stable since Angular 22)
via native CVA interop, as well as to template-driven (`[(ngModel)]`) and reactive
(`[formControl]`) forms. Whichever API is used, the error is **dynamic**: it only appears
after interaction and clears automatically once the field becomes valid again. `required` also
shows the `*` marker on the label. No need to force `level="error"`.

## Resizing

By default, the native handle lets you enlarge the field **vertically**. `resize`
(`none`/`vertical`/`horizontal`/`both`) changes the axis. With `autoResize`, the height follows
the entered content and the handle is disabled.

```html
<!-- Signal Forms -->
<ui-textarea [formField]="field" label="Message" placeholder="Your message…" />

<!-- Reactive forms + error message -->
<ui-textarea formControlName="bio" label="Bio" errorText="Minimum 20 characters" required />

<!-- Auto-resize: height follows the content -->
<ui-textarea [(ngModel)]="message" label="Message" autoResize />
```

> Architecture: `ui-textarea` shares the `ui-field` shell (label + box + helper + states) with
> `ui-input` and the `BaseFormField` base (CVA + validation). `ui-field`'s `multiline` mode
> opens up the box (top-aligned, automatic height with `min-height`). The Figma subcomponent
> `_ui-textarea-content` is carried natively by the `<textarea>`, and the "resizer" by the
> native handle.
