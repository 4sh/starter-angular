# ui-label

Native form field label (`<label>`), used standalone or composed inside other
components (`ui-checkbox`, `ui-radio`, `ui-input`… via `ui-field`). The text comes from the
`label` input or from content projected via `<ng-content>`; `for` links the label to the id of the
labeled form element.
