## Forms

The component implements <code>ControlValueAccessor</code> (via <code>BaseControlValueAccessor</code>):
it works standalone, with **Signal Forms** (`@angular/forms/signals`, `[formField]`
directive, stable since Angular 22) via native CVA interop, with <code>[(ngModel)]</code>
or in reactive forms.

<Canvas of={CheckboxStories.SignalForms} />

```html
<!-- Standalone -->
<ui-checkbox label="Accept the terms" (checkboxChange)="onToggle($event)" />

<!-- Signal Forms -->
<ui-checkbox [formField]="accepted" label="Accept the terms" />

<!-- Template-driven -->
<ui-checkbox [(ngModel)]="accepted" label="Accept the terms" />

<!-- Reactive -->
<ui-checkbox formControlName="accepted" label="Accept the terms" required />
```

- The **error style applies automatically** when the attached control is invalid **and**
  touched/dirty (the CVA's `showError` rule); `invalid` lets you force it.
- `disabled` can come from the input **or** from `control.disable()` (forms API).
- `trueValue` / `falseValue` customize the model's values (e.g. `'yes'` / `'no'`).

      <td><strong>Semantics</strong></td>
      <td>Native <code>type="checkbox"</code> input: Space toggles, screen reader announcement, native <code>disabled</code> and <code>required</code>.</td>
    </tr>
    <tr>
      <td><strong>Labeling</strong></td>
      <td>The component is a native <code>&lt;label&gt;</code> wrapping the input: clicking anywhere (box, spacing, text) checks it. With no visible label: <code>ariaLabel</code> required (or <code>ariaLabelledBy</code>).</td>
    </tr>
    <tr>
      <td><strong>Indeterminate</strong></td>
      <td>Native DOM property → announced as <em>mixed</em> by screen readers, no manual ARIA needed.</td>
    </tr>
    <tr>
      <td><strong>States</strong></td>
      <td><code>:focus-visible</code> = ring distinct from hover. <code>aria-invalid</code> set when the error style is active.</td>
    </tr>
    <tr>
      <td><strong>Icons</strong></td>
      <td>The box and its check are <code>aria-hidden</code> (the state is carried by the native input).</td>
    </tr>
