# ui-file-upload-list

File row — the **repeated unit** of an upload list (mirrors the
Figma component). [ui-file-upload](?path=/docs/components-ui-forms-ui-file-upload--docs)
stacks one per file. Presentational: thumbnail (images) or file
icon, name + size/state, remove button. During upload, the
marker switches to `ui-spinner` and a progress bar appears.
