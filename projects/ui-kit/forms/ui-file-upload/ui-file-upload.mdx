# ui-file-upload

**Headless** file uploader — compact field (`field`) or a
**drag-and-drop** zone (`drag`). Selection relies on a native
`<input type="file">` (visually hidden but focusable): system picker, keyboard and
screen readers work natively, and the whole surface accepts drops. Files are
validated client-side (type / size / count) then uploaded automatically
(`auto`), on demand, or via a custom handler (`customUpload`). Progress
is tracked via `XMLHttpRequest` (no global HTTP provider required);
image thumbnails use object URLs that are revoked on removal.

<Canvas of={FileUploadStories.Basic} />

> ℹ️ **Not a form control**: unlike the kit's other fields,
> `ui-file-upload` does **not** implement `ControlValueAccessor` — it wires up
> neither to `[(ngModel)]`, nor to reactive forms / Signal Forms, and doesn't participate
> in their validation. This is a deliberate choice: the value (`UiUploadFile[]`,
> `File` objects + upload state) isn't serializable into a form
> model. Drive it via the dedicated API — `files` / `filesChange`, `selected`,
> `uploaded`, `removed` — and feed the result (ids, URLs) back into your
> form if needed.

## Advanced

The advanced uploader offers drag-and-drop, multiple files,
automatic upload, progress tracking and validation.

<Canvas of={FileUploadStories.Advanced} />

## Custom Upload

The upload implementation can be replaced by enabling `customUpload`
and defining a custom handler (`uploadHandler`). The handler
receives the pending files and callbacks (`setProgress` / `markUploaded` /
`markError`) to drive the state.

<Canvas of={FileUploadStories.CustomUpload} />

## Image Preview

Grid preview with thumbnails + name / size. Hovering an image reveals the
remove button. Built via the `content` template.

<Canvas of={FileUploadStories.ImagePreview} />

## Template

The UI is customizable via templates. `file` (implicit variable: the
file) replaces a row's rendering. `content` receives the selected files
and lets you manage the uploaded files (e.g. removal). `toolbar` displays custom
content in the actions bar.

```html
<!-- Real upload to an endpoint -->
<ui-file-upload
  mode="drag"
  [multiple]="true"
  accept="image/*,.pdf"
  [maxFileSize]="5 * 1024 * 1024"
  url="/api/upload"
  ariaLabel="Upload documents"
  (uploaded)="onUploaded($event)"
  (uploadError)="uploadError($event)"
/>
```

## Composition

The file list is composed of **`ui-file-upload-list`** rows (one per
file) — the same unit as in Figma. Each row switches to `ui-spinner`
during upload. See [ui-file-upload-list](?path=/docs/components-ui-forms-ui-file-upload-list--docs).
