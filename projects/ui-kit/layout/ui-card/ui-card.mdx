# ui-card

**Flexible** container that composes optional regions: media, header
(title + subtitle), content and footer. Each region is only rendered if it
carries content — no empty wrapper, so no ghost spacing.

Neutral surface (`global` tokens): background `--global-background-default`, text
`--global-text-default`, border `--global-border-subtle`, shadow
`--shadow-default-md` (`elevated` variant), radius `--radius-lg`. Light **and** dark
via variable modes.

## Slot system

The common case needs **no import**: default content flows through
`<ng-content>`, and the title / subtitle accept the `header` / `subheader` inputs.
Rich slots use **marker directives** (attribute or element) that need to be
imported in the host component.

```html
<ui-card header="Title" subheader="Subtitle">
  Card content (default slot)
</ui-card>

<ui-card>
  <img uiCardMedia src="…" alt="…" />
  <span uiCardTitle>Title <ui-tag label="New" /></span>
  <span uiCardSubtitle>Subtitle</span>
  Rich content…
  <div uiCardFooter>
    <ui-button label="Cancel" level="low" />
    <ui-button label="Confirm" />
  </div>
</ui-card>
```

## Full-bleed content (`contentFlush`)

By default the content carries the card's gutter. `contentFlush` **removes**
it to let the consumer control the layout: full-bleed media/color band,
full-width table… The gutter is still available via the `--ui-card-padding`
CSS variable (re-apply it on blocks that should stay inset).

```html
<ui-card header="Title" [contentFlush]="true">
  <div class="flex-y" style="--flex-gap-y: var(--units-md)">
    <div class="banner"></div> <!-- full width -->
    <p style="padding-inline: var(--ui-card-padding)">Re-guttered paragraph…</p>
  </div>
</ui-card>
```

## Footer

```html
<!-- actions grouped on the right -->
<div uiCardFooter class="flex-x flex-gap-x align-right" style="--flex-gap-x: var(--units-sm)">
  <ui-button label="Cancel" level="low" />
  <ui-button label="Confirm" />
</div>

<!-- tags on the left, action on the right -->
<div uiCardFooter class="flex-x align-justify" style="flex:1;align-items:center">
  <div class="flex-x flex-gap-x"><ui-tag … /><ui-tag … /></div>
  <ui-button label="Action" />
</div>
```
