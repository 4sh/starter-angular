# ui-modal

**Headless** modal window: a floating surface styled by tokens, rendered above
a viewport mask and driven by the two-way `visible` model. Appearance / disappearance
go through the **motion system** (mask fade + dialog `zoom` by default, overridable
via `motion`). Built for accessibility: **focus trap** with restoration
(`@angular/cdk/a11y`), `aria-modal`, **background scroll lock**, keyboard closing
(`Escape`), and optional closing on outside click.

The dialog composes three regions: a `header` (plain string or `#header` template), the
default content (`<ng-content>`, which **scrolls internally** if long) and a footer via
the `#footer` template. It handles `draggable`, `maximizable`, nine positions, modal /
non-modal mode and breakpoint-based widths (`breakpoints`).

## Content & templates

- `header` (string) or `#header` (rich content) for the title.
- `<ng-content>` for the body.
- `#footer` for the actions.
- `#closeicon` to replace the close icon.

## Dragging

`draggable` enables grabbing the dialog by its header (action buttons don't
trigger dragging). `keepInViewport` (default) keeps it within the screen bounds;
`minX` / `minY` bound the top-left corner. Dragging applies via the independent
`translate` CSS property, without interfering with the `zoom` animation.

## Resizing

`resizable` adds a handle at the bottom-right corner of the dialog (pointer only,
like a `textarea` corner). Minimum sizes are bounded by `minWidth` /
`minHeight`. For keyboard-driven size control, use `maximizable`.

<Canvas of={ModalStories.Resizable} />

## Embedded (`contained`)

`contained` scopes the dialog to the nearest positioned ancestor (`position: absolute`
instead of `fixed`) and **does not affect** body scroll: ideal for embedding a modal
in a bounded container (panel, preview). The parent container must be positioned
(`position: relative`).

<Canvas of={ModalStories.Contained} />

## Modal / non-modal

In `modal` mode (default), the mask darkens and **blocks** background scroll;
`dismissableMask` allows closing on outside click. In non-modal mode, the background
stays **interactive and scrollable** (`blockScroll` can still freeze scroll).

## Accessibility

<table className="doc-table">
  <thead>
    <tr>
      <th>Rule</th>
      <th>Detail</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>Role & name</strong></td>
      <td><code>role="dialog"</code> + <code>aria-modal="true"</code>. Accessible name via <code>aria-labelledby</code> (header title), otherwise <code>ariaLabel</code> / <code>ariaLabelledBy</code>. A dev warning flags a dialog with no accessible name.</td>
    </tr>
    <tr>
      <td><strong>Focus</strong></td>
      <td>Focus trap (<code>cdkTrapFocus</code>) while the dialog is open; focus is captured on open (<code>focusOnShow</code>) and **restored** to the triggering element on close.</td>
    </tr>
    <tr>
      <td><strong>Keyboard</strong></td>
      <td><code>Escape</code> closes (<code>closeOnEscape</code> + <code>closable</code>). Native <code>&lt;button&gt;</code> header buttons with <code>aria-label</code>; maximizing exposes <code>aria-pressed</code>.</td>
    </tr>
    <tr>
      <td><strong>Background scroll</strong></td>
      <td>Blocked when <code>modal</code> (or <code>blockScroll</code>), with scrollbar-gutter compensation (no layout shift). Shared counter: scroll is restored when the last dialog closes.</td>
    </tr>
    <tr>
      <td><strong>Outside click</strong></td>
      <td>Optional via <code>dismissableMask</code> (modal only); disabled by default to avoid accidental closes.</td>
    </tr>
    <tr>
      <td><strong>Motion</strong></td>
      <td>Respects <code>prefers-reduced-motion</code> and the global <code>data-motion="off"</code> switch; can be disabled per dialog via <code>motionDisabled</code>.</td>
    </tr>
  </tbody>
</table>
