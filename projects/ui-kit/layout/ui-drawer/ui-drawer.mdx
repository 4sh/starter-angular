# ui-drawer

Headless **sliding** panel anchored to a screen edge: a surface styled by tokens,
rendered above an optional viewport mask and driven by the two-way `visible`
model. Appearance / disappearance go through the **motion system** — the mask
fades while the panel **slides in from its edge** (the direction is derived from
`position`, the distance stretched to the panel's own size). Built for accessibility:
**focus trap** with restoration (`@angular/cdk/a11y`), `aria-modal`, **background
scroll lock**, keyboard closing (`Escape`) and optional closing on outside click.

The panel composes three regions: a `header` (plain string or `#header` template), the
default content (`<ng-content>`, which **scrolls internally** if long) and a footer via
the `#footer` template. A `#headless` template takes over **the entire inside** of the
panel when full control of the UI is needed.

## Position

The panel anchors to one of four edges via `position` (`left`, `right`, `top`, `bottom`)
and slides in from that edge. The motion preset is **automatically derived** from the position.

<Canvas of={DrawerStories.Position} />

## Full screen

`fullScreen` extends the panel to the whole viewport; the appearance then switches
to a fade (no full-screen slide).

<Canvas of={DrawerStories.FullScreen} />

## Responsive width

The panel's size is driven via `drawerStyle` (or `styleClass`). A fluid value like
`min(90vw, 28rem)` keeps the panel on screen on mobile while capping it on large
screens.

<Canvas of={DrawerStories.Responsive} />

## Content & templates

- `header` (string) or `#header` (rich content) for the title.
- `<ng-content>` for the body.
- `#footer` for the actions.
- `#closeicon` to replace the close icon.

<Canvas of={DrawerStories.Template} />

## Headless mode

`#headless` replaces **the entire inside** of the panel (header, content, footer) with
custom content, while the drawer keeps the overlay mechanics: mask, motion, focus
trap and `Escape` closing. Ideal for a fully custom navigation panel.

<Canvas of={DrawerStories.Headless} />

## Embedded (`contained`)

`contained` scopes the panel to the nearest positioned ancestor (`position: absolute`
instead of `fixed`) and **does not affect** body scroll: ideal for embedding a drawer
in a bounded container (panel, preview). The parent container must be positioned
(`position: relative`).

## Accessibility

<table className="doc-table">
  <thead>
    <tr>
      <th>Rule</th>
      <th>Detail</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>Role & name</strong></td>
      <td><code>role="dialog"</code> + <code>aria-modal="true"</code> (in modal mode). Accessible name via <code>aria-labelledby</code> (header title), otherwise <code>ariaLabel</code> / <code>ariaLabelledBy</code>. A dev warning flags a panel with no accessible name.</td>
    </tr>
    <tr>
      <td><strong>Focus</strong></td>
      <td>Focus trap (<code>cdkTrapFocus</code>) while the panel is open; focus is captured on open (<code>focusOnShow</code>) and **restored** to the triggering element on close.</td>
    </tr>
    <tr>
      <td><strong>Keyboard</strong></td>
      <td><code>Escape</code> closes (<code>closeOnEscape</code> + <code>closable</code>). Native <code>&lt;button&gt;</code> close button with <code>aria-label</code>.</td>
    </tr>
    <tr>
      <td><strong>Background scroll</strong></td>
      <td>Blocked when <code>modal</code> (or <code>blockScroll</code>), with scrollbar-gutter compensation (no layout shift). Shared counter: scroll is restored when the last panel closes.</td>
    </tr>
    <tr>
      <td><strong>Outside click</strong></td>
      <td>Enabled by default via <code>dismissableMask</code> (modal only); can be disabled for a blocking panel.</td>
    </tr>
    <tr>
      <td><strong>Motion</strong></td>
      <td>Respects <code>prefers-reduced-motion</code> and the global <code>data-motion="off"</code> switch; can be disabled per panel via <code>motionDisabled</code>.</td>
    </tr>
  </tbody>
</table>
