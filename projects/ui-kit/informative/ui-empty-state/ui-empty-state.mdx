# ui-empty-state

Communicates the **absence of content** (empty list, no search results, an
up-to-date inbox…) and offers a way out.

<Canvas of={EmptyStateStories.Default} />

## API

<ArgTypes of={EmptyStateStories} />

The **visual** and the **actions** are projected via marker directives:

```html
<ui-empty-state title="Empty inbox" description="You're all caught up.">
  <!-- Visual: illustration / image / SVG (replaces the `icon` shorthand) -->
  <img uiEmptyStateMedia src="/illustrations/empty.svg" alt="" />
  <!-- Actions -->
  <div uiEmptyStateActions>
    <ui-button label="New message" level="high" icon="pen" />
  </div>
</ui-empty-state>
```

A **free body** (default content) can also be projected between the description
and the actions for rich cases (mini form, list of suggestions…).

## Visual: icon or illustration

Two paths, mutually exclusive (a projected illustration wins over the `icon` shorthand):

- **`icon` shorthand**: a FontAwesome name, rendered large via `ui-icon` (decorative).
- **`uiEmptyStateMedia` slot**: a custom illustration, image or SVG.

<Canvas of={EmptyStateStories.WithIllustration} />

The visual area is **shown by default**; `showMedia = false` hides it without
removing the visual from the markup (text-only empty state).

## Accessibility

<table className="doc-table">
  <thead>
    <tr>
      <th>Point</th>
      <th>Implementation</th>

  </thead>
  <tbody>
    <tr>
      <td><strong>Decorative visual</strong></td>
      <td>The shorthand icon is decorative (<code>aria-hidden</code> via <code>ui-icon</code>): meaning comes from the title and description, never from the visual alone. A projected illustration carries its own <code>alt</code>/<code>aria-label</code> (or <code>alt=""</code> if purely decorative).</td>
    </tr>
    <tr>
      <td><strong>Region (landmark)</strong></td>
      <td>Setting <code>ariaLabel</code> (or <code>ariaLabelledBy</code>) adds <code>role="region"</code> to expose the empty state as a navigable landmark. With no name, no role is imposed (avoids an anonymous landmark).</td>
    </tr>
    <tr>
      <td><strong>Title</strong></td>
      <td>Rendered as a styled paragraph (no imposed heading level) so it doesn't disturb the document outline; link it to your own <code>&lt;h*&gt;</code> via <code>ariaLabelledBy</code> if the empty state forms a section.</td>
    </tr>
    <tr>
      <td><strong>Dynamic appearance</strong></td>
      <td>If the empty state replaces content that was loading, announce it via a live region on the container (e.g. <code>aria-live="polite"</code>) rather than stealing focus.</td>
    </tr>
    <tr>
      <td><strong>Actions</strong></td>
      <td>Actions are real <code>ui-button</code>s / native links (keyboard focus, accessible name). Color is never the sole carrier of meaning.</td>
    </tr>
  </tbody>
</table>
