# ui-chip

Compact, **interactive** token representing an entity: a value selected in a
multi-select, an active filter, a keyword from a list… Close to `ui-tag` but **actionable**:
it accepts a leading icon or **image** (avatar-style), an optional **remove
action**, free **projected content**, and a **selectable** mode (choice / filter
chip toggle) for entity selection.

## API

## Basic

Displays compact information, with an optional remove action (`removable`).
The `remove` event is emitted on click or keyboard activation of the remove action.

<Canvas of={ChipStories.Removable} />

## Levels & intensity

Five families (`default`, `highlight`, `success`, `warning`, `error`) × two intensities
(`low` subtle, the chip's default, `high` strong).

## Icon

An icon (FontAwesome name) can precede the label via `icon`. Combine with `removable` to
add the remove action.

<Canvas of={ChipStories.Icon} />
<Canvas of={ChipStories.IconRemovable} />

## Image

`image` shows an avatar-style leading image (takes priority over `icon`). On a failed
load, the chip falls back to the icon/label and emits `imageError`.

<Canvas of={ChipStories.Image} />

## Template

Custom content can be projected into the chip (default slot) in place of the plain
`label`. In that case, set `ariaLabel` to guarantee an accessible name.

<Canvas of={ChipStories.Template} />

## Selectable

With `selectable`, the chip becomes a **toggle** (choice / filter chip): the root is a
keyboard-focusable `<button aria-pressed>`, a click (or `Enter`/`Space`) toggles the
`selected` state (two-way). When selected, the chip takes on its family's **strong**
fill (`high`) and shows the `selectedIcon` (`check` by default) leading. `selectable` and
`removable` are mutually exclusive.

<Canvas of={ChipStories.Selectable} />

## Examples

```html
<!-- Basic, removable -->
<ui-chip label="Angular" removable (remove)="onRemove()" />

<!-- Icon + removal -->
<ui-chip label="Filter" level="highlight" icon="filter" removable />

<!-- Image (avatar-style) -->
<ui-chip label="Jane Doe" image="/assets/jane.png" alt="" removable />

<!-- Strong intensity, small -->
<ui-chip label="Active" level="success" subLevel="high" size="small" />

<!-- Icon-only (accessible name required) -->
<ui-chip icon="user" ariaLabel="User" level="highlight" />

<!-- Custom content (Template) -->
<ui-chip level="highlight" ariaLabel="Jane Doe online" removable>
  <span class="status">● Jane Doe</span>
</ui-chip>

<!-- Selectable (toggle) -->
<ui-chip selectable [(selected)]="interested" label="Photography" icon="camera" />
```
