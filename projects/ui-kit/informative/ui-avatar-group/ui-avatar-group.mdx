# ui-avatar-group

Stacks a set of `ui-avatar`s with a slight overlap. A simple **headless layout
container**: it only arranges its projected children. The overlap comes from the
shared constant `$avatar-group-overlap` (`src/styles/src/settings/_ui-config.scss`).

<Canvas of={GroupStories.Default} />

## "+N" overflow

The component doesn't compute truncation itself: express the surplus by projecting a last
avatar in Label mode (e.g. `+5`).

## Accessibility

<table className="doc-table">
  <thead>
    <tr>
      <th>Point</th>
      <th>Implementation</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>Grouping</strong></td>
      <td>The root carries <code>role="group"</code>. Each <code>ui-avatar</code> keeps its own accessible name.</td>
    </tr>
    <tr>
      <td><strong>"+N" avatar</strong></td>
      <td>Set <code>ariaLabel</code> (e.g. "5 other members") to describe the surplus.</td>
    </tr>
  </tbody>

```html
<ui-avatar-group>
  <ui-avatar image="/a.jpg" alt="Alice" />
  <ui-avatar image="/b.jpg" alt="Bob" />
  <ui-avatar label="+5" ariaLabel="5 other members" />
</ui-avatar-group>
```
