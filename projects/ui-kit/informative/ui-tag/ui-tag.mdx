# ui-tag

Informative label (pill): a short label categorized by **color family**
(`level`) and **intensity** (`subLevel`), with an optional icon on each side.
**Static** component (non-interactive).

100% driven by the **design tokens** of the `informative` category
(`--informative-{level}{sub}-surface|content|stroke-*`), like `ui-badge`.
Customization goes through the built-in variants (`level`/`subLevel`/`size`), not
CSS overrides.

## Levels & intensity

(`high` strong, `low` subtle).

## Examples

```html
<!-- Simple -->
<ui-tag label="Active" level="success" />

<!-- Subtle intensity + left icon -->
<ui-tag label="Draft" level="highlight" subLevel="low" iconLeft="pen" />

<!-- Small, with right icon -->
<ui-tag label="Error" level="error" size="small" iconRight="times-circle" />

<!-- Rounded rectangle -->
<ui-tag label="Beta" level="highlight" [rounded]="false" />

<!-- Icon-only (accessible name required) -->
<ui-tag iconLeft="star" ariaLabel="Favorite" level="warning" />
```
