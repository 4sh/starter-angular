## Accessibility

<table className="doc-table">
  <thead>
    <tr>
      <th>Point</th>
      <th>Implementation</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>Text content</strong></td>
      <td>The <code>value</code> is text read in-flow. The icon is decorative (<code>aria-hidden</code> via <code>ui-icon</code>); color is never the sole carrier of meaning.</td>
    </tr>
    <tr>
      <td><strong>Ambiguous counter</strong></td>
      <td>Set <code>ariaLabel</code> to remove ambiguity (e.g. "3" → "3 unread messages").</td>
    </tr>
    <tr>
      <td><strong>Icon-only</strong></td>
      <td><code>ariaLabel</code> mandatory (a warning fires in dev otherwise).</td>
    </tr>
    <tr>
      <td><strong>Dot</strong></td>
      <td>Decorative: meaning comes from the parent context (e.g. a "Notifications" button that already carries its label).</td>
    </tr>
  </tbody>
</table>

```html
<!-- Counter tied to a context -->
<button aria-label="Messages, 3 unread">
  Messages <ui-badge level="error" [value]="3" ariaLabel="3 unread" />
</button>
```
