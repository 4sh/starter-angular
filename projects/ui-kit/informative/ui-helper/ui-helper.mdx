## Accessibility

<table className="doc-table">
  <thead>
    <tr>
      <th>Point</th>
      <th>Implementation</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>Message</strong></td>
      <td>The text carries the information; the icon is <strong>decorative</strong> (<code>aria-hidden</code> via <code>ui-icon</code>). Color is never the sole carrier of meaning (text + icon).</td>
    </tr>
    <tr>
      <td><strong>Field association</strong></td>
      <td>Link it to the form field via <code>aria-describedby</code> pointing to the helper's <code>id</code>.</td>
    </tr>
    <tr>
      <td><strong>Dynamic feedback</strong></td>
      <td><code>ariaLive="polite"</code> (or <code>"assertive"</code> for a blocking error) so changes are announced.</td>
    </tr>
  </tbody>
</table>

<Canvas of={HelperStories.LiveError} />

```html
<!-- Error helper tied to a field -->
<input id="email" aria-describedby="email-help" aria-invalid="true" />
<ui-helper id="email-help" level="error" ariaLive="assertive" message="Invalid email address." />
```
