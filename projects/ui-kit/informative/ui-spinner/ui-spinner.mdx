# ui-spinner

Headless **indeterminate** loading indicator. Renders a smooth SVG circle by
default, colored by the tokens (`--global-text-default`, overridable via
`--ui-spinner-color`). The animated marker is **fully replaceable**: image,
FontAwesome icon, or free template. Motion respects `prefers-reduced-motion`
and the global `data-motion="off"` switch.

## Replaceable marker

The marker is chosen by **input presence**, in this priority order:

1. `spinnerTemplate`: free content (`TemplateRef`)
2. `image`: image URL (shown as-is: an animated GIF/SVG carries its own motion)
3. `icon`: FontAwesome name (rotated by the component)
4. *default*: built-in SVG circle (`strokeWidth` / `fill` / `animationDuration`)

## Avoiding the flash

For a very short wait, a spinner that flashes for a fraction of a second
degrades the UX. `delay` (ms) defers its appearance: if the content arrives
before the delay elapses, the spinner is never mounted.

```html
<!-- Only appears if loading exceeds 300 ms -->
<ui-spinner [delay]="300" label="Loading" />
```
