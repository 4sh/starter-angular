# ui-alert

**Inline** message for informational, success, warning or error feedback.

Unlike [`ui-toast`](/docs/components-ui-informative-ui-toast--docs) (floating
notification, service-driven), `ui-alert` sits within the page's flow: a form
banner, an error summary, an inline status. The root carries `role="alert"`
(implicit `aria-live="assertive"` + `aria-atomic="true"`): the message is announced as soon as
it appears.

## Icon

The leading icon is driven by `icon`: a FontAwesome name to override,
`false` to hide it, `true` (default) for the level's default icon.

<Canvas of={AlertStories.CustomIcon} />
<Canvas of={AlertStories.NoIcon} />

## Variant

The sub-level (`subLevel`) modulates the intensity: `high` (strong) or `low` (subtle).

<Canvas of={AlertStories.SubLevelLow} />

## Sizes

Two sizes: `default` and `large`.

<Canvas of={AlertStories.Large} />

## Dynamic

Several messages display via an `@for` block; each removes itself on close.

<Canvas of={AlertStories.Dynamic} />

## Life

Setting `life` (ms) makes the alert disappear automatically (it hides and
emits `closed`).

<Canvas of={AlertStories.Life} />

```html
<ui-alert level="success" text="Saved." [life]="4000" (closed)="onClose()" />
```

A form's validation errors display at `error` severity.
