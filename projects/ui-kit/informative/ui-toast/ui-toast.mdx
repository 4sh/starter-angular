# ui-toast

Transient notification, stacked in a corner of the screen. The component splits into
three complementary pieces:

- **`UiToast`**: the presentational card (icon · title/text · close). Fully
  driven by the `informative` tokens (surface / content / stroke), in both `light` and `dark`.
- **`UiToastService`**: the programmatic entry point (`add` / `addAll` / `clear` / `remove`).
- **`ui-toast-container`**: the stack anchored in the viewport: it reads the service, positions
  the toasts, animates the enter/exit via the shared **motion system** and manages auto-dismiss
  (paused on hover / focus).

> **`breakpoints` (PrimeNG)** is **not** carried over: the stack's width is already responsive

> per breakpoint, which wouldn't align with the design system's token-first approach.

## Motion

Enter/exit is wired to the shared **motion system** (`animate.enter` /
`animate.leave` + the `uiMotion` directive). The preset is chosen based on the position
(`slide-down` at the top, `slide-up` at the bottom, `zoom` in the center) and overridable via the
`motion` input. The global `data-motion="off"` kill switch and the *reduced-motion*
preference are respected automatically.
