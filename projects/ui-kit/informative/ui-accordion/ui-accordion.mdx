# ui-accordion

**Headless** accordion: a group of collapsible panels. **Composition** API —
a `ui-accordion` container drives the open
state, and `ui-accordion-panel`s project their header and content.

Opening/closing is animated by the shared **motion system**
(`utils.motion-transition`, `grid-template-rows` technique), which automatically
respects `prefers-reduced-motion` and the global `data-motion="off"` switch.

## Modes

**Single** mode (default): only one panel open at a time; re-clicking the
active header closes it. **Multiple** mode (`[multiple]="true"`): several panels open,
`value` becomes an array.

<Canvas of={AccordionStories.Multiple} />

## Rich header

The `uiAccordionHeader` slot accepts any content (icon, `ui-tag`, badge…).
With no slot, the `header` input is enough for a text title.

<Canvas of={AccordionStories.RichHeader} />

## States

A `disabled` panel isn't collapsible and is skipped by the arrow keys. The chevron and
the rule can be disabled (per group or per panel).

<Canvas of={AccordionStories.DisabledPanel} />
<Canvas of={AccordionStories.Minimal} />

## Animation

Opening/closing uses the shared **motion system**. Turn it off locally
with `[motion]="false"`, globally via `data-motion="off"`, or let the system's
`reduced-motion` preference neutralize it. See **Foundations → Motion**.

## Examples

```html
<!-- Single (one open at a time) -->
<ui-accordion [(value)]="open">
  <ui-accordion-panel value="a" header="Section A">Content A…</ui-accordion-panel>
  <ui-accordion-panel value="b" header="Section B">Content B…</ui-accordion-panel>
</ui-accordion>

<!-- Multiple + rich header + disabled panel -->
<ui-accordion [(value)]="openList" [multiple]="true">
  <ui-accordion-panel value="a">
    <span uiAccordionHeader>Billing <ui-tag label="Up to date" level="success" size="small" /></span>
    Content…
  </ui-accordion-panel>
  <ui-accordion-panel value="b" header="Archived" [disabled]="true">Content…</ui-accordion-panel>
</ui-accordion>

<!-- No animation -->
<ui-accordion [motion]="false"> … </ui-accordion>
```
