# ui-read-only

Displays a **read-only labeled value** (label / value pair). Purely
presentational: no interactive state, no form participation — to enter a
value, use the `forms/` components.

## Layout

`layout="vertical"` stacks the label above the value; `layout="horizontal"` places them
side by side. In horizontal, `labelWidth` fixes the label column's width (to align
several rows) and `labelAlign` controls the label text's alignment.

<Canvas of={ReadOnlyStories.Horizontal} />
<Canvas of={ReadOnlyStories.HorizontalFixedLabel} />

## Full layout control (grid / utility classes)

For **fine-grained, responsive control**, `layout="grid"` leaves the component with **no
imposed layout**: your grid system (Gridaflex) or your utility classes drive everything,
injected via `rowClass` (`<dl>` row), `labelClass` (`<dt>` cell) and `valueClass` (`<dd>`
cell). These three inputs are **additive across every layout** — they also complement
`vertical`/`horizontal` when needed.

<Canvas of={ReadOnlyStories.GridLayout} />

```html
<!-- Gridaflex: label column 6/24, value 18/24 on desktop, full width on mobile -->
<ui-read-only
  layout="grid"
  rowClass="flex-x flex-gap-x"
  labelClass="cell phone-24 desktop-6"
  valueClass="cell phone-24 desktop-18"
  label="Label"
  value="…" />
```

## Sitting alongside a form field

By default a read-only stays **compact** (tight label→value gap, value sized to its content) —
ideal for a standalone summary card. When it **sits alongside fields**, enable **`matchField`**: the
component then reuses the field's **label→value gap** (`--units-sm` / `--units-xs` in `small`) **and**
sizes the **value area to the field's height** (value centered, no horizontal padding). Combined
with the shared label (`ui-label`), the alignment is **pixel-perfect**.

<Canvas of={ReadOnlyStories.NextToField} />

## Content & states

`fallback` shows (muted) when the value is empty/null. `multiline` preserves line
breaks. Projected content replaces the text value with a rich value.

```html
<!-- Plain value -->
<ui-read-only label="Email" value="test@test.com" />

<!-- Fixed label column, right-aligned -->
<ui-read-only layout="horizontal" labelWidth="140px" labelAlign="right" label="Role" value="Engineer" />

<!-- Projected rich value -->
<ui-read-only label="Status">
  <ui-badge level="success" value="Active" icon="check" />
</ui-read-only>
```

## Theming

The component is presentational: font sizes are local typography tokens
(`$sizes` at the top of the `.scss`) and the label column's width is set per instance via
the `labelWidth` input (`--ui-read-only-label-width` custom property). `matchField` mode
**consumes** the field's shared constants (gap + height; no new constant):
