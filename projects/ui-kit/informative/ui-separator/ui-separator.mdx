# ui-separator

**Visual and semantic** dividing line between two pieces of content. Headless component:
it renders a `role="separator"` element whose rule comes from the design tokens
(`--global-border-default` for the line, `--stroke-*` for the thickness).

An optional `label` turns the rule into a separator **with a label**; `labelAlign`
places the text at the start, center or end.

    </tr>
    <tr>
      <td><strong>Decorative</strong></td>
      <td>With no label, the separator remains a semantic break. If it is purely decorative in an already-structured context, prefer an <code>aria-hidden</code> on the parent.</td>
    </tr>

```html
<!-- Simple full-width rule -->
<ui-separator />

<!-- Centered "OR" separator -->
<ui-separator label="OR" labelAlign="center" />

<!-- Vertical between two actions in a toolbar -->
<div style="display:flex; align-items:stretch; height:24px">
  <button>Edit</button>
  <ui-separator orientation="vertical" />
  <button>Delete</button>
</div>
```

## Theming

No local variable overridable per instance: the line comes from `--global-border-default`,
its thickness from `--stroke-default`/`--stroke-sm` (`size="small"`), the label from the
`global.*` typography tokens. See how the [configuration works](?path=/docs/components-configuration--docs).
