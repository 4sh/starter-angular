# ui-skeleton

Placeholder shown **in place of content** while it loads. Renders a
single box colored by tokens (`--global-background-muted`,
overridable via `--ui-skeleton-background`). Three shapes (`text`, `circle`,
`rectangle`) provide default dimensions; `width` / `height` /
`borderRadius` accept a raw CSS value to compose cards, grids,
lists and tables. Motion respects `prefers-reduced-motion` and
the global `data-motion="off"` switch.

## Shapes

Varied shapes and sizes via `shape`, `width`, `height`, `borderRadius` and
`size`.

```html

<ui-skeleton shape="rectangle" />
<ui-skeleton shape="circle" />
<ui-skeleton shape="rectangle" size="small" />
<ui-skeleton shape="rectangle" width="10rem" height="4rem" borderRadius="8px" />
```

## Animation

The base animation is **`wave`**: a light, wide, soft shine slides from
left to right and fades at the edges (tint drivable via
`--ui-skeleton-shine`, automatically dimmed in dark theme). `pulse`
offers an opacity pulse instead; `none` freezes the box. All
stop under `prefers-reduced-motion` or `data-motion="off"`.

```html
<ui-skeleton animation="wave" />
<ui-skeleton animation="pulse" />
<ui-skeleton animation="none" />
```

## Accessibility

<table className="doc-table">
  <thead>
    <tr>
      <th>Point</th>
      <th>Implementation</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>Ignored by screen readers</strong></td>
      <td>The root carries <code>aria-hidden="true"</code>: loading is a purely visual state, never announced as content.</td>
    </tr>
    <tr>
      <td><strong>Loading region</strong></td>
      <td>Group several skeletons under a container carrying <code>aria-busy="true"</code> to flag the area as loading.</td>
    </tr>
    <tr>
      <td><strong>Keyboard</strong></td>
      <td>No interactive element: the component is never in the tab order.</td>
    </tr>
    <tr>
      <td><strong>Reduced motion</strong></td>
      <td><code>prefers-reduced-motion: reduce</code> and <code>data-motion="off"</code> freeze the animation.</td>
    </tr>
  </tbody>
</table>

```html
<!-- Loading area -->
<div [attr.aria-busy]="loading">
  @if (loading) {
    <ui-skeleton width="100%" />
    <ui-skeleton width="80%" />
  } @else {
    <!-- content -->
  }
</div>
```
