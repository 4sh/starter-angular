# ui-progress-bar

Process status indicator.

## API

<ArgTypes of={ProgressBarStories} />

## Basic

Reflects the percentage progress of an ongoing process.

<Canvas of={ProgressBarStories.Basic} />

## Dynamic

The value is reactive: updating it animates the bar accordingly (the
width transitions via the shared motion system).

<Canvas of={ProgressBarStories.Dynamic} />

## Template

The displayed value can be freely formatted via `valueTemplate` (context
`{ $implicit: value }`) and the bar recolored via `color`. Here several bars
share the same progress with different formatters.

<Canvas of={ProgressBarStories.Template} />

```html
<ui-progress-bar [value]="70" [valueTemplate]="fraction" ariaLabel="Progress" />
<ng-template #fraction let-v>{{ v / 10 }} / 10</ng-template>
```

## Indeterminate

For processes whose progress isn't measurable, set `mode` to
`indeterminate`: the bar loops with no displayed value.

<Canvas of={ProgressBarStories.Indeterminate} />

## As Steps

`steps` splits the bar into N discrete segments to represent step-based
progress; the number of filled segments is derived from `value`.

<Canvas of={ProgressBarStories.AsSteps} />

## Value inside the gauge

`valuePosition="inside"` embeds the percentage **inside the fill** of the
bar (centered, contrasted text `informative.highlightHigh.content`). The track
grows to accommodate the text; the label is clipped if the fill is
too narrow.

<Canvas of={ProgressBarStories.ValueInside} />

```html
<ui-progress-bar [value]="50" valuePosition="inside" ariaLabel="Progress" />
```

## Customization

The fill color is overridable per instance via the `color` input
(or directly the `--ui-progress-bar-color` custom property), without breaking
the encapsulation:

```html
<ui-progress-bar [value]="80" color="var(--informative-successhigh-surface-default)" />
```
