# ui-label

Label de champ de formulaire natif (`<label>`), utilisé seul ou composé à l'intérieur d'autres
composants (`ui-checkbox`, `ui-radio`, `ui-input`… via `ui-field`). Le texte vient de l'input
`label` ou d'un contenu projeté via `<ng-content>` ; `for` relie le label à l'id de l'élément
de formulaire labellisé.
