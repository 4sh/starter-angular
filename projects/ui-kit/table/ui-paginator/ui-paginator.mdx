# ui-paginator

**Standalone** pagination bar: first/previous, page numbers,
next/last, and an optional "rows per page" selector.

Used internally by `ui-table` (`paginator`), it also works standalone
on any collection: bind `totalRecords`, `rows` and the two-way
`first`.

<Canvas of={PaginatorStories.Basic} />

```html
<ui-paginator
  [totalRecords]="items.length"
  [(rows)]="rows"
  [(first)]="first"
  [rowsPerPageOptions]="[5, 10, 20]"
  (pageChange)="onPage($event)"
/>
```

## Rows per page

`rowsPerPageOptions` shows the selector; choosing a value updates `rows`
and returns to the first page.

<Canvas of={PaginatorStories.WithRowsPerPage} />

## Page window

Past `pageLinks` pages, the number window recenters on the current
page; the boundary controls disable natively.

<Canvas of={PaginatorStories.ManyPages} />

## Compact mode (`ellipsis`)

`ellipsis` replaces the sliding window with the compact
`1 2 3 … 30 31 32` form: `boundaryCount` pages at each edge, the
current page's neighborhood, and decorative (non-focusable) `…`s in the
gaps — a single-page gap is shown rather than elided.

<Canvas of={PaginatorStories.Ellipsis} />
<Canvas of={PaginatorStories.EllipsisMiddle} />

## Current-page report

`showCurrentPageReport` shows `1 - 10 of 120` in front of the controls; the
`currentPageReportTemplate` pattern accepts the placeholders `{first}`
`{last}` `{rows}` `{page}` `{pageCount}` `{totalRecords}`. Combined with
`showFirstLastIcon="false"` / `showPageLinks="false"`, the bar reduces to
a report + previous/next.

<Canvas of={PaginatorStories.CurrentPageReport} />

## Template

Each element of the bar is customizable via a named template, and the
bar can **embed free content**:

<table className="doc-table">
  <thead>
    <tr><th>Template</th><th>Role</th><th>Context</th></tr>
  </thead>
  <tbody>
    <tr><td>`#start` / `#end`</td><td>Free content before the controls / after the selector (label, counter, actions…).</td><td>`{ $implicit: state }` (`first`, `last`, `rows`, `page`, `pageCount`, `totalRecords`)</td></tr>
    <tr><td>`#report`</td><td>Rich page report (replaces the text pattern).</td><td>same</td></tr>
    <tr><td>`#firsticon` / `#previcon` / `#nexticon` / `#lasticon`</td><td>Control icons.</td><td>—</td></tr>
    <tr><td>`#pagelink`</td><td>Content of a page number.</td><td>`{ $implicit: number, page, active }`</td></tr>
  </tbody>
</table>

Accessibility attributes (name, `aria-current`, `disabled`) stay
carried by the buttons regardless of the injected content.

<Canvas of={PaginatorStories.Template} />

```html
<ui-paginator
  [totalRecords]="120"
  [rowsPerPageOptions]="[10, 30, 120]"
  showCurrentPageReport
  [showFirstLastIcon]="false"
  [showPageLinks]="false"
>
  <ng-template #start>Rows per page:</ng-template>
  <ng-template #end let-state>page {{ state.page + 1 }} / {{ state.pageCount }}</ng-template>
</ui-paginator>
```
