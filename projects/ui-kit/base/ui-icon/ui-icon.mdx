# ui-icon

Displays an icon by its name (`name`, e.g. `circle-user`), in `solid` or `outline`, at five
sizes (`sm` → `xl`). **FontAwesome** is the default family, but the component supports
**any icon font family** (see _Icon families_). **Decorative by
default** (ignored by screen readers): if the icon carries information on its own, pass
`decorative=false` + `ariaLabel`.

## Icon families

Each family's rendering is described by a `UiIconFamily` (how to build the CSS
classes and, for ligature fonts like Material Symbols, the text content). FontAwesome is
built in; other families are registered via `provideUiIconFamilies()`:

```ts
// app.config.ts
import { provideUiIconFamilies } from '@4sh/ui-kit/base/ui-icon';

export const appConfig: ApplicationConfig = {
  providers: [
    provideUiIconFamilies(
      {
        material: {
          classes: () => 'material-symbols-outlined',
          content: (name) => name, // ligature font: the name is the content
        },
        bootstrap: { classes: (name) => `bi bi-${name}` },
      },
      { default: 'material' }, // optional: changes the default family
    ),
  ],
};
```

```html
<!-- Usage per family -->
<ui-icon name="home" family="material" />
<ui-icon name="alarm" family="bootstrap" />
<ui-icon name="circle-user" family="fontawesome" />
```

> The matching font must be loaded by the project (CSS/webfont). An unknown family
> key falls back to `fontawesome` (with a warning in dev).
