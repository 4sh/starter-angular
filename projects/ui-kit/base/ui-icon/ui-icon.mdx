# ui-icon

Affiche une icône par son nom (`name`, ex. `circle-user`), en `solid` ou `outline`, à cinq
tailles (`sm` → `xl`). **FontAwesome** est la famille par défaut, mais le composant supporte
**n'importe quelle famille de police d'icônes** (voir _Familles d'icônes_). **Décorative par
défaut** (ignorée par les lecteurs d'écran) : si l'icône porte une information isolément, passe
`decorative=false` + `ariaLabel`.

## Familles d'icônes

Le rendu de chaque famille est décrit par une `UiIconFamily` (comment construire les classes
CSS et, pour les polices à ligatures comme Material Symbols, le contenu texte). FontAwesome est
intégré ; on enregistre d'autres familles via `provideUiIconFamilies()` :

```ts
// app.config.ts
import { provideUiIconFamilies } from '@4sh/ui-kit/base/ui-icon';

export const appConfig: ApplicationConfig = {
  providers: [
    provideUiIconFamilies(
      {
        material: {
          classes: () => 'material-symbols-outlined',
          content: (name) => name, // police à ligature : le nom est le contenu
        },
        bootstrap: { classes: (name) => `bi bi-${name}` },
      },
      { default: 'material' }, // optionnel : change la famille par défaut
    ),
  ],
};
```

> La police correspondante doit être chargée par le projet (CSS/webfont). Une clé de famille
> inconnue retombe sur `fontawesome` (avec un warning en dev).

### Trois échelles d'application

Une fois la famille enregistrée, **trois leviers** la posent, à trois granularités. Ils se
combinent : le plus proche de l'icône gagne.

```html
<!-- Une icône -->
<ui-icon name="home" family="material" />
<ui-icon name="alarm" family="bootstrap" />

<!-- Un sous-arbre : tout ce qui est en dessous bascule -->
<form uiIconFamily="material">
  <ui-datepicker [(ngModel)]="date" valueType="date" label="Date" />
</form>
```

<Canvas of={IconStories.ScopedFamily} />

**Pourquoi la directive existe.** La majorité des icônes d'un composant sont **internes** : les dix
chevrons du panneau de `ui-datepicker`, la coche et la loupe de `ui-select`… aucun input ne les
expose, donc aucune surcharge ponctuelle ne les atteint. La directive re-déclare la famille par
défaut dans son *element injector* : chaque `ui-icon` descendant la voit, y compris ceux d'un
panneau **monté en overlay CDK** — la relocalisation DOM ne change pas la chaîne d'injecteurs.

**Critère de choix.** Vous visez *une* icône → `family` (ou un template d'icône, quand c'est le
markup entier qui change : voir [`ui-input`](?path=/docs/components-ui-forms-ui-input--docs)).
Vous visez *une zone* → la directive. Vous visez *tout le projet* → l'option `default`.
